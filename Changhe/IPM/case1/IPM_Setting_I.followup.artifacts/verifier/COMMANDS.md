# Command sequences of the verifier's numerical audits

Several topics were run through a short shell sequence called by the topic's launcher, which also recorded process and timing data. The shell scripts, launchers and process records are not included (the launchers in `code/` call them and therefore do not run as published); this file lists each sequence, with the environment line, the echo lines and the waits for earlier jobs removed. Set

```
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1
```

and run the commands in bash from the top of the accompanying artifacts folder (the folder containing `lead/`, `numerics/` and `verifier/`). Inputs read from `numerics/runs/` are the files of `numerics/data/` (copy them there first). Where a sequence reads `"$1"` or `"$@"`, set `sourcefile` or the tag list as shown. Inputs larger than 500 kB that are not included (for example `verifier/inverse/verification/dnSB_directions.npz`) are regenerated by the programs of their topic.
