# Independent verification of the refreshed 72-grid state

Date: 2026-10-20. This is a numerical verification protocol, written before evaluating the new state. It asserts no existence or convergence theorem.

The input is the numerical researcher's second 72 by30 state at compactification scale L=8, copied byte for byte from artifacts/data/dnC_n72m30S.npz. Interpret its binary nodal table at the ideal Chebyshev-Lobatto radial nodes and warped angular midpoint nodes, exactly as in ../inverse/PROOF.md. It is a distinct represented density from the B-state in ../third-grid/PROOF.md. A small change in a solver's residual is not assumed to imply a small change in the independently reconstructed physical residual.

Define the canonical whole-plane velocity by the paired inverse in ../inverse/PROOF.md, with no adjustable harmonic strain. At a physical point X, define R=(c_l X+U).grad rho-rho, E=-partial_x U_2+partial_y U_1-partial_x rho, N_f=|rho|+sum_i |(c_l X_i+U_i)partial_i rho|, and N_v=|rho|+|X.grad rho|+|U.grad rho|. All finite maxima below refer to the fixed58point set already used for all three scales and resolutions, not to a continuum supremum.

Recompute the density and velocity with this lane's own reconstruction and split paired kernel. Use two inverse resolutions, three eighth-order Cartesian density-difference steps, and a separate analytic chain-rule gradient. Independently find the positive nonzero canonical axis root x*, verify the source Jacobian at two steps, and evaluate R and E at (x*,0.1) and(x*,1). Check both coordinate reflections, U(0)=0, the unit cubic normalization and the exact center conditions. The finite-difference and inverse-resolution changes are sensitivity measurements, not certified error bounds.

The omitted exterior contribution is bounded exactly as in ../domain-states/PROOF.md. With H^2 at least2N(2M-1), integer B0 at least max|b_ij| and C=L^3 H B0, the represented density is bounded by C r^(1/c_l) beyond radius1. Pairing opposite source points cancels the first velocity kernel term. For evaluation radius a<R and1/c_l<1/5, the remaining integral outside R is bounded by (5C/2)a R^(-4/5)/(1-a^2/R^2)^2. Set R=10^30 and retain this term separately from the uncertified interior quadrature. This compactification scale is not a finite physical boundary.

Use the exact JSON interface to import every binary nodal value and parameter. The center regularity certificate in ../center-regularity/PROOF.md tests whether forbidden fifth-degree angular components or the exact transport-balance determinant exclude the particular interpolant. Compute the canonical center moment in two independently justified ways: the finite radial/Bessel formula of ../center-moment/PROOF.md and the periodic analytic-strip enclosure of ../center-moment-trapezoid/PROOF.md. Each includes its own truncation estimate; their overlap is a consistency check. No harmonic gauge correction is made to force3c_l-1-psi_xy(0)=0. The exact nodal data and all proof/code dependencies are pinned.

The implementations copied into this topic are this verifier's own previously completed programs, with their provenance recorded. No numerical-lane implementation is imported. Compare the completed C-state results with the frozen B-state using the same samples and denominators where appropriate. The C-state's reported collocation residual and reported Ritz values remain attributed quantities unless independently recomputed. A second stagnation is not proof of a minimum, a solution family, a smooth limit or either task endpoint.
