A declared run cap is a scheduled deadline. For start T0 and observed time t, elapsed time so far is t minus T0. A future deadline cannot be the observed end time or elapsed duration. This follows from the definitions of elapsed and end times, without assumptions about whether the shift loop eventually completes. The report must leave T_end unreached until actual termination, or label it explicitly as scheduled. This is a reporting audit, not a mathematical result about IPM.
