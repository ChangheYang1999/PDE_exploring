## A.3.73 The hydrostatic problem on the axis

(a) Since g is even in xi, g_xi(0, y) = 0 and V_1(0, y) = -int_y^inf g_xi(0, t) dt = 0, so (3) on the axis reads v G' = G. By |g_xixi| <= C (1 + r)^{gamma - 2} the integral int_y^inf g_xixi(0, t) dt converges, and differentiating V_2(0, y) = int_0^y t g_xixi(0, t) dt + y int_y^inf g_xixi(0, t) dt gives v' = c + int_y^inf g_xixi(0, t) dt and v'' = -g_xixi(0, y), continuous since g is C^2. V_2 is odd in y, so v(0) = 0, and |V| <= C' (1 + r)^gamma (3.72(d)) gives v(y)/y -> c. As y -> 0, G(y)/y -> G'(0) = 1 and v(y)/y -> v'(0), so v G' = G gives v'(0) = 1; in particular v, G and G' are positive on some interval (0, delta). If v had a first zero y1 > 0, then G'/G = 1/v > 0 on (0, y1), so G(y1) >= G(delta/2) > 0, while v(y1) G'(y1) = 0 contradicts v G' = G at y1. So v > 0 on (0, inf), G(y) = G(y0) exp(int_{y0}^y dt/v(t)) > 0 and G' = G/v > 0. For (2), integration by parts gives int_0^R (1 - t/R) (-v''(t)) dt = [-(1 - t/R) v'(t)]_0^R - R^{-1} int_0^R v'(t) dt = v'(0) - v(R)/R = 1 - v(R)/R. If g_xixi(0, .) >= 0 on (0, inf), the left side of (2) is nonnegative for every R, while the right side tends to 1 - c < 0. From G'/G = 1/v and v(t)/t -> c, log G(y) = (p + o(1)) log y. If v(t) - c t = O(t^beta) with beta < 1, then 1/v(t) - 1/(c t) = O(t^{beta - 2}) is integrable on [1, inf), so log G(y) - p log y converges as y -> inf, and G ~ K y^p with 0 < K < inf. If g is C^3 near 0 with the stated expansion, then g_xixi(0, y) = 2 B y + o(y), so v'' = -2 B y + o(y) and, with v(0) = 0 and v'(0) = 1, v = y - (B/3) y^3 + o(y^3); on the other hand G = y + E y^3 + o(y^3), G' = 1 + 3 E y^2 + o(y^2) and v = G/G' = y - 2 E y^3 + o(y^3). Hence B = 6E.

(b) On [0, inf), v' = c - D/(1 + y^2) >= 1, v(y) - y = D (y - arctan y) >= 0, v <= c y and v'' = 2 D y/(1 + y^2)^2 > 0 for y > 0. The function 1/v(t) - 1/t = -D (t - arctan t)/(t v(t)) is odd and real analytic on R, since t - arctan t = t^3 w(t^2) with w analytic and v(t)/t = 1 + D (t - arctan t)/t >= 1; so G is odd and real analytic, G'/G = 1/v by differentiation, G' > 0, and G <= y on (0, inf) because 1/v <= 1/t there. Since v(t) - c t = -D arctan t is bounded, G ~ K y^p with 0 < K < inf as in (a). From v = y + D y^3/3 + O(y^5), 1/v(t) - 1/t = -D t/3 + O(t^3), so G = y (1 - D y^2/6 + O(y^4)). If phi is odd and smooth with support in [-y2, -y1] u [y1, y2], 0 < y1 < y2, let m > 0 be the minimum over [y1, y2] of v - y and v''; if ||phi||_{C^2} < m, then v + phi has v + phi > y and (v + phi)'' > 0 on [y1, y2], and it coincides with v elsewhere, so the properties above hold for v + phi and the corresponding G (the relations at 0 and as y -> inf are unchanged, and the bound v + phi >= y gives 0 < G <= y). These phi form an infinite-dimensional set.

(c) The identity h_y = g_xi is -Phi_yy = g_xi; b_y = c - h_xi is d_xi V_1 + d_y V_2 = 0, which holds classically for the velocity (2) of 3.72 (both derivatives are int_y^inf g_xixi dt up to sign); a g_xi + b g_y = g is (3). Substituting the expansions: order xi^0 of b_y = c - h_xi gives v' = c - h_1; order xi of h_y = g_xi gives h_1' = 2 g_2, so g_2 = -v''/2; order xi^2 of the transport equation gives 2 (c + h_1) g_2 + v g_2' + G' b_2 = g_2, which is the stated formula for b_2 after inserting h_1 and g_2; order xi^2 of b_y = c - h_xi gives b_2' = -3 h_3, and order xi^3 of h_y = g_xi gives h_3' = 4 g_4. In general the order xi^{2k} of the transport equation is linear in b_{2k} with coefficient G' and otherwise involves only coefficients already determined, and the other two equations then give h_{2k+1} and g_{2k+2}. Where q = g_y > 0, the transport equation gives b = (g - a h_y)/q, and b_y = c - h_xi gives h_xi = c - d_y((g - a h_y)/q). Replacing (g, h) by (g + u, h + z) and keeping first-order terms, with a replaced by a + z and b = (g - a h_y)/q, gives u_xi = z_y and z_xi = -d_y((u - h_y z - a z_y - b u_y)/q). At an axis point a = 0 and h_y = g_xi = 0 by parity, so a_y = h_y = 0 and h_yy = g_xiy = 0 there, q = G'(y0) and b = v(y0). The z-equation then reads z_xi = (v/q) u_yy + (terms in u_y and u), with no terms in z, z_y or z_yy at that point. For frozen coefficients and the modes exp(lambda xi + i eta y): lambda u = i eta z and lambda z = -(v/q) eta^2 u + O(|eta|) u, so lambda^2 = -i (v/q) eta^3 + O(eta^2). The square roots of -i eta^3 have real parts +-|eta|^{3/2}/sqrt(2) for both signs of eta, which gives the stated real parts. The growth exp(k |eta|^{3/2} xi), k > 0, of one root is faster than any power of |eta|, so no estimate of a fixed Sobolev norm of the solution at xi > 0 by a fixed Sobolev norm of the data holds for the frozen system; the parity z = 0 on the axis does not help: there the two roots are lambda_0 and -lambda_0 (the z-equation has no z terms at the frozen point), and the data u = u_0, z = 0 at xi = 0 give u = u_0 cosh(lambda_0 xi) for each mode.

(d) (i) By g_y(0) = 1, F(0) = 1. On the axis g(0, y) = y F(beta y^2) = O(y^gamma), so F(s) -> 0 as s -> inf. Since g_xi = 2 alpha xi y F'(alpha xi^2 + beta y^2) = (alpha/beta) xi d_y(F(alpha xi^2 + beta y^2)), formula (2) of 3.72 gives h = V_1 = (alpha/beta) xi F(s), s = alpha xi^2 + beta y^2. The centre condition (a) gives d_xi V_1(0) = -int_0^inf g_xixi(0, t) dt = c - 1 = D, so alpha/beta = D. Differentiate (3) in y and set y = 0, where g = g_xi = g_yy = 0, b = 0, g_y = F(s), g_xiy = 2 alpha xi F'(s) and b_y = c - h_xi = c - D F(s) - 2 D s F'(s), s = alpha xi^2: (c xi + D xi F)(2 alpha xi F') + (c - D F - 2 D s F') F = F, that is 2 c s F'(s) = D F(s) (F(s) - 1) for all s > 0. Near 0, where F > 0, Z = (F - 1)/F satisfies s Z' = nu Z with nu = D/(2c) in (0, 1/2), so Z = k s^nu and F(alpha xi^2) = 1/(1 - k alpha^nu |xi|^{2 nu}). Since F(alpha xi^2) = g_y(xi, 0) is C^1 in xi and 2 nu < 1, k = 0, so F = 1 near 0, and uniqueness for this ODE on s > 0 (locally Lipschitz there) gives F = 1 on [0, inf), contradicting F(s) -> 0. (ii) g_y(0) = f(0) G_0'(0) = 1, so f(0) != 0, and G_0 is unbounded because G(y) = f(0) G_0(y) = y^{p + o(1)} by (a). The bound |g_xi| = |f'(xi) G_0(y)| <= C (1 + r)^{gamma - 1} at fixed xi and y -> inf forces f'(xi) = 0 for every xi, so g = f(0) G_0(y), and |g_y| = |f(0) G_0'(y)| <= C (1 + r)^{gamma - 1} at fixed y and xi -> inf forces G_0' = 0, contradicting G_0'(0) != 0. (iii) Iterating, g(X) = l^{-n} g(l^n X) for all integers n; letting l^n -> 0 and using differentiability at 0 gives g(X) = grad g(0) . X = y (parities and g_y(0) = 1), which violates |g| <= C (1 + r)^gamma. For the scalings: if g~(xi, y) = (lambda^2/mu) g(xi/lambda, y/mu), then the velocity (2) of g~ is (lambda V_1, mu V_2) evaluated at (xi/lambda, y/mu), so (3) is preserved, and g~_y(0) = (lambda/mu)^2 g_y(0); invariance g~ = g with g_y(0) = 1 forces lambda = mu, and then g~(X) = lambda g(X/lambda).
