3.73 The hydrostatic problem on the axis, the evolution in xi, and three excluded forms ((a)-(d) derived in an external analysis; hand-checked in the main analysis; AUDITPLACEHOLDER). Let c > 1, p = 1/c and D = c - 1, and let g be a C^2 density, even in xi and odd in y, with g_y(0) = 1 and the three bounds of 3.72(d) for some C and 0 < gamma < 1, which with the velocity V of (2) of 3.72 solves (3) of 3.72 with c_lim = c. For y >= 0 put G(y) = g(0, y) and v(y) = c y + V_2(0, y). (a) Axis reduction. On the axis V_1 = 0, and
@@    v G' = G,   v'(y) = c + int_y^inf g_xixi(0, t) dt,   v'' = -g_xixi(0, .),   v'(0) = 1,   v(y)/y -> c;   (1)
v, G and G' are positive on (0, inf), and for every R > 0
@@    int_0^R (1 - t/R) g_xixi(0, t) dt = 1 - v(R)/R,  which tends to 1 - c as R -> inf.   (2)
So the centre condition int_0^inf g_xixi(0, t) dt = 1 - c of 3.72(e) is the relation v'(0) = 1, which the axis equation forces, and g_xixi(0, y) >= 0 for all y > 0 is impossible. Integrating G'/G = 1/v gives G(y) = y^{p + o(1)} as y -> inf; if moreover v(y) - c y = O(y^beta) for some beta < 1, then G(y) ~ K y^p with 0 < K < inf. If g is C^3 near 0 and g = y + B xi^2 y + E y^3 + o(r^3), then (1) gives B = 6E, the case eps = 0 of 3.72(a). (b) The axis conditions select neither G nor c. For every c > 1 the odd real-analytic functions v(y) = c y - D arctan y and G(y) = y exp(int_0^y (1/v(t) - 1/t) dt) satisfy v G' = G, v'(0) = 1, v(y)/y -> c, v'' > 0 on (0, inf), G' > 0 and 0 < G(y) <= y on (0, inf), G(y) ~ K y^p with 0 < K < inf, and G = y - (D/6) y^3 + O(y^5). Adding to v an odd smooth function supported in [-y2, -y1] u [y1, y2], 0 < y1 < y2, with C^2 norm below a constant depending on c, y1 and y2, preserves all these properties, so for each c the axis data compatible with (1), (2) and these signs form an infinite-dimensional family. They are axis data, not solutions of (3). (c) Formal expansion and evolution in xi. Write h = V_1, a = c xi + h and b = c y + V_2; then h_y = g_xi, b_y = c - h_xi and a g_xi + b g_y = g. Where G' > 0, the formal expansion g = G + xi^2 g_2 + xi^4 g_4 + ..., h = xi h_1 + xi^3 h_3 + ..., b = v + xi^2 b_2 + ... is determined by G: h_1 = c - v', g_2 = -v''/2, b_2 = ((4c - 1 - 2v') v'' + v v''')/(2 G'), h_3 = -b_2'/3, g_4 = -b_2''/12, and in general each b_{2k} is obtained by dividing by G' and h_{2k+1}, g_{2k+2} by differentiation. So at fixed c the formal data are one odd function G, subject to the conditions of (a) and, at each order, to the conditions as y -> inf that the formula (2) of 3.72 imposes; this gives neither convergence nor existence. Where q = g_y > 0, the equations give the evolution system g_xi = h_y, h_xi = c - d_y((g - a h_y)/q) in xi. Its linearization at a solution, (u, z) for (g, h) at fixed c, is u_xi = z_y, z_xi = -d_y((u - h_y z - a z_y - b u_y)/q); with coefficients frozen at an axis point (0, y0), y0 > 0, the characteristic roots lambda at vertical frequency eta satisfy lambda^2 = -i (v(y0)/G'(y0)) eta^3 + O(eta^2), so Re lambda = +-(v(y0)/(2 G'(y0)))^{1/2} |eta|^{3/2} + o(|eta|^{3/2}), and the frozen Cauchy problem with data on the axis has no continuous solution operator between Sobolev spaces with any fixed loss of derivatives. This is a statement about the frozen model, not an ill-posedness theorem for (3) (the coefficient a vanishes only on the axis); it shows that marching in xi from the axis is not a justified construction, so solutions of (3) must be sought as a global problem. (d) Excluded forms. No g as above has any of the forms (i) g = y F(alpha xi^2 + beta y^2) with alpha, beta > 0 and F a function on [0, inf); (ii) g = f(xi) G_0(y); (iii) g(X) = l g(X/l) for all X and one l in (0, 1) or (1, inf). Under the scalings (xi, y, g) -> (lambda xi, mu y, (lambda^2/mu) g), which map solutions of (3) without the normalization g_y(0) = 1 to solutions, the normalization forces lambda = mu, so (iii) contains invariance under any nontrivial scaling of this kind. Scope: these statements describe necessary conditions and obstructions for the hydrostatic problem; they neither construct a solution of (3) nor exclude one, and say nothing about the bounds needed in 3.72(e).
