3.72 Exact anisotropic rescaling by the slope, and the large-slope limit of the canonical inverse ((a) and (b) proposed in the main analysis; (a)-(d) proved by the checker, with numerical checks; (a), (b), the phenomenon of (c) with a second example, and versions of (d) and (e) under bounds on all derivatives derived independently in an external analysis; hand-checked in the main analysis, with a numerical check of the strain formulas of (c); AUDITPLACEHOLDER). Let a0 != 0, s = sgn a0, h = |a0|^{1/2} and eps = 1/|a0|. (a) Put x = h xi, rho(x, y) = a0 g(xi, y), psi(x, y) = h Phi(xi, y) and V = (-Phi_y, Phi_xi) = (U_1/h, U_2). Then rho is a profile of the class with slope a0 and exponent c_l if and only if g is smooth, even in xi and odd in y, satisfies the growth bounds of the class in the variables (xi, y), and
@@    (c_l xi + V_1) g_xi + (c_l y + V_2) g_y = g,   -Phi_yy - eps Phi_xixi = s g_xi,   g_y(0) = 1,   (1)
with Phi odd in both variables and V = o(|(xi, y)|); for each eps > 0 this velocity is unique. The centre strain is unchanged, psi_xy(0) = Phi_xiy(0), so the origin condition reads Phi_xiy(0) = 1 - c_l. If rho = a0 y + b x^2 y + e y^3 + O(r^5), then g = y + B xi^2 y + E y^3 + O(|(xi, y)|^5) with B = s b and E = e/a0, and (T1) of 3.3 becomes 6E = (s - 2 A eps) B. On the y-axis g(0, y) ~ (K/a0) y^p with K/a0 > 0 (3.6), and the representative with L_K = 1 (that is K = a0) has g(0, y) ~ y^p. So the slope is an anisotropy parameter: a profile with slope a0 is a solution with unit slope of the problem whose elliptic operator is -d_y^2 - eps d_xi^2, and |a0| -> inf is formally the hydrostatic limit -Phi_yy = s g_xi. For fixed a0 the map is a change of coordinates, not a symmetry of the profile equation. (b) For c_l > 1 and K != 0, rho = K sgn(y) |y|^p with U = 0 solves the profile equation in the sense of distributions on R^2. It is Holder continuous of order p, not C^1 on the x-axis, violates the gradient bound of the class as x -> inf at fixed y != 0, and is outside the class (its trace K sgn(sin th) |sin th|^p is excluded as a far field by 3.7). It is a candidate singular outer state at fixed K: identifying it as a limit of smooth profiles would need matching and convergence arguments, and no such approximation is proved here (3.7 excludes this trace for each profile, but not convergence of smooth traces to it without uniform angular regularity). (c) For inputs with only the density and gradient bounds of the class, the canonical centre strain of (1) need not stay bounded as eps -> 0, and a sublinear hydrostatic inverse need not exist. For 0 < gamma < 1, g = exp(-xi^2) y (1 + y^2)^{(gamma - 2)/2} is smooth, has the parities, g_y(0) = 1 and the density and gradient bounds with exponent gamma, but for s = 1 its canonical centre strain satisfies eps^{gamma/2} Phi_xiy(0) -> -2 Gamma(2 - gamma) Gamma(gamma)/Gamma(1 - gamma/2) < 0, and no velocity of sublinear growth with the parities solves -Phi_yy = g_xi. The external analysis finds the same rate, with the limit constant -2 B(gamma, 3 - gamma) (B the Beta function), for y (1 + y^2)^{(gamma - 2)/2}/(1 + xi^2). These functions are not profiles. (d) One more bound gives the limit. Let 0 < gamma < 1 and let g be smooth with the parities, |g| <= C (1 + r)^gamma, |grad g| <= C (1 + r)^{gamma - 1} and |g_xixi| <= C (1 + r)^{gamma - 2}, r = |(xi, y)|, and let V_eps be the canonical velocity of -Phi_yy - eps Phi_xixi = g_xi. Then |V_eps| <= C' (1 + r)^gamma with C' depending only on C and gamma, and as eps -> 0, V_eps converges locally uniformly to the velocity V_0 given for y >= 0 by
@@    V_0,1 = -int_y^inf g_xi(xi, t) dt,   V_0,2 = int_0^y t g_xixi(xi, t) dt + y int_y^inf g_xixi(xi, t) dt,   (2)
which is the unique velocity with the parities and sublinear growth solving -Phi_yy = g_xi; moreover Phi_eps,xiy(0) = int_0^inf (P_{sqrt(eps) t} * g_xixi(., t))(0) dt -> int_0^inf g_xixi(0, t) dt, where P_a(z) = a/(pi (a^2 + z^2)) and * is the convolution in xi. The limiting stream Phi_0(xi, y) = int_0^inf min(y, t) g_xi(xi, t) dt is C^1, Phi_0,yy exists and is continuous and -Phi_0,yy = g_xi holds classically; no regularity of the full velocity gradient is asserted. The same convergence holds for inputs g_eps that converge in C^2 on compact sets and obey the three bounds with common C and gamma. (e) Conditional consequence. Let rho_n be exact profiles with a0,n -> +inf and c_l,n -> c_lim, and suppose that representatives g_n (in the sense of (a)) satisfy the three bounds of (d) with one C and one gamma in (0, 1) and converge in C^2 on compact sets to g_lim. By 3.6 and the density bound, c_l,n >= 1/gamma, so c_lim >= 1/gamma > 1. Then g_lim is a C^2 density which, with the velocity V given by (2), solves the hydrostatic profile problem
@@    (c_lim xi + V_1) g_xi + (c_lim y + V_2) g_y = g,   -Phi_yy = g_xi,   g_y(0) = 1,   (3)
pointwise, with the three bounds, |V| <= C' (1 + r)^gamma and the stream regularity stated in (d), and int_0^inf g_xixi(0, t) dt = 1 - c_lim. Hence: fix C > 0, 0 < gamma < 1, a compact interval J and finite constants C_R (R > 0), and suppose that for no c_lim in J does (3), with the velocity (2), have a C^2 density satisfying the three bounds with these C and gamma. Then there is M = M(J, C, gamma, (C_R)) such that no exact profile with c_l in J and a0 >= M has a representative satisfying the three bounds with C and gamma and |D^3 g| <= C_R on each disc of radius R. A conclusion for every C and gamma needs the nonexistence premise for every C and gamma. The report establishes neither nonexistence for (3) nor the uniform estimates needed to apply this argument to all large-slope profiles, and by (c) the bounds of the class alone do not give the limit of the inverse. For a0,n -> -inf (s = -1) the limiting velocity is minus the velocity (2), the stream equation is -Phi_yy = -g_xi, the centre condition is int_0^inf g_xixi(0, t) dt = c_lim - 1, and the same argument applies to this signed problem. Scope: (a) and (b) are exact statements; (c)-(e) concern the inverse operator and conditional limits; these results neither construct a profile of the class nor give an unconditional nonexistence theorem for it. For the computed states of 4.7(c), 2 A eps = 10/a0 lies between 0.451 and 0.507, so the correction in the exact cubic identity 6E = (s - 2A eps) B is not small.
