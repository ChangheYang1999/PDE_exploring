# Independent re-gauged density, axis widths and box comparison

Scope. These are finite evaluations of five saved, nonstationary trial densities. No exact profile, continuum convergence or first-crossing theorem is asserted. Dependencies: this lane's verified scalar Q reader, exact jet table, and spatial dilation identity. The checker uses no producer evaluation or differentiation code.

Write rho(x,y)=y w(t) sum_{k=0}^{M-1} sigma(t)^k beta_k(t) cos(2k theta), where r=L sqrt(sigma)/(1-t)^P, sigma=(1+t)/2, w=(1-t)/2. The actual density exponent is p=1-1/P. The axis coefficient is K=L^(1/P)/2 times sum_k (-1)^k beta_k(1), and a=beta_0(-1). Thus the genuine dilation length giving K_l=a is l=(a/K)^P. With rho_l(X)=l rho(X/l), define g(xi,y)=rho_l(sqrt(a)xi,y)/a for these positive-slope states. This defines a complete physical field at each saved state; using the report's rounded K=10 and P=3/2 yields negligibly different numerical lengths but is recorded separately rather than equated to the literal encoded field.

At y=0 the ratio rho_y(x,0)/a equals w sum sigma^k beta_k/a. At x=0 the ratio rho(0,y)/(a y) equals w sum (-sigma)^k beta_k/a. Both follow directly by dividing the displayed polynomial representation by y and taking the corresponding parity limit. After dilation their argument is r/l. Hence axis half-widths can be evaluated without near-axis finite differences. We first reproduce the producer's stated geometric sample grid and then use a separate denser logarithmic grid to bracket a crossing of 1/2, followed by Brent's scalar root method. Every reported root is a bracketed numerical crossing; no unsampled earlier crossing is excluded by a proof. The selected sampled crossing and bracket must agree between independent grids before treating them as the same width.

For the box comparison use exactly the 61 by 60 coordinate set xi=i/20 (i=0,...,60) and y=.05+j*.05 (j=0,...,59). Evaluate g with the independent scalar polynomial reader and stored coefficients, subtract the N192 reference and record both maximum and location. A maximum on this finite set is neither a supremum over the continuous box nor an error against any unknown limit. A second independently shifted/finer grid can test sampling sensitivity. The values and their changes are diagnostics only; the sequence of Taylor coefficients is compatible with convergence, divergence or oscillation beyond the finite data.

Multiprecision spot checks at the selected largest-difference locations and at axis crossings use exact rational coefficients and a separate density implementation. The dilation length and amplitude used in each comparison must be fixed consistently before comparing arithmetic precision. Checks at two precisions test arithmetic stability only and do not provide interval-certified error bounds.
