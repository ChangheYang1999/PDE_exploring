# the T2 theory worker artifacts

Reproduction of every number reported by lane the T2 theory worker. Python: python3
Run from this directory; all scripts use the standard library unless stated.

Setup (needed once, before any script that reads a large input). To keep this directory under 20 MB, the eleven
input copies larger than 400 kB are stored gzip-compressed (since 2026-10-29T09:04Z). Restore them in place and check them:

    gunzip -k data/*.json.gz data/*/*.json.gz && sha256sum -c data/COMPRESSED_INPUTS.sha256

The scripts assert the sha256 of the uncompressed files, so a wrong restore stops them. Delete the uncompressed copies
afterwards to keep the size limit.

Lane copies in ../scratch (inputs, keep them). Some scripts read frozen copies of other lanes' texts that the T2 theory worker made
at the time of a check, with their sha256 asserted: ../scratch/h18/ (arith/h18_item2_check.py), ../scratch/v08check/
and ../scratch/v08check2/ (arith/check_v08_factors.py, arith/check_v08_preview1_r2.py, arith/check_v08_preview2.py),
../scratch/falsify/ (arith/falsify_section0.py, arith/check_v08_factors.py). Their rows say "lane copy".

Replaying in order. Several results files record their own run time (keys elapsed, elapsed_s, elapsed_seconds,
seconds, utc, 'lane rerun utc'), and some scripts assert the sha256 of an upstream results file (data/family_ceilings_exact_results.json
in arith/h18_item2_check.py, arith/h18_wu_sharp.py, arith/review_t4_459.py; data/h18_item2_check_results.json in
arith/h18_wu_sampling.py, arith/h18_wu_sharp.py; data/review_t4_462_results.json in arith/t4_468_scope.py). Rerunning an
upstream script in place changes that hash through its timing keys, and the downstream script then stops at its
assertion although nothing of substance changed. To replay, either restore the distributed upstream file before each
downstream script, or use arith/replay_sweep.py (last row), which runs every script in a mirror tree on the distributed
inputs and compares outputs up to the timing keys.
