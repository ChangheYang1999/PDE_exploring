## Statement and hypotheses

rho_n=r^(1-n/2) sum_q t^q F_(n,q)(theta),
psi_n=r^(2-n/2) sum_q t^q G_(n,q)(theta), t=log r.

For sine amplitudes a_(n,q,j) at frequency 2j+1 and b_(n,q,j) at frequency 2j, put M_(n,q)=sum_j |a_(n,q,j)|, N_(n,q)=sum_j |b_(n,q,j)|. Define M_n=sum_q M_(n,q), N_n=sum_q N_(n,q). For nonconstant columns, define H_n=max_(q>=1) q! M_(n,q)/M_(n,0). The maximization excludes q=0. A value H_n<1 means no nonconstant factorial-weighted column exceeds the constant column at that finite order. It does not bound later orders or imply convergence for unbounded t.

## Exact identities checked

Let P=2-n/2. Applying the polar Laplacian to r^P t^q G gives, for each nonnegative q and positive j,

(4j^2-P^2)b_(q,j) - 2P(q+1)b_(q+1,j) - (q+1)(q+2)b_(q+2,j)
= ((P-2j)a_(q,j-1)+(q+1)a_(q+1,j-1)+(P+2j)a_(q,j)+(q+1)a_(q+1,j))/2.

Missing entries are zero. This follows from -[(P+D_t)^2+D_theta^2]G=[cos(theta)(P-1+D_t)-sin(theta)D_theta]F. When 4j^2=P^2, the same polynomial identity remains valid and the chosen b_(0,j)=0 fixes the homogeneous term. The zero angular stream mode vanishes by odd reflection.

For the stationary equation, direct Cartesian differentiation gives

[2(1-n/2)-1] F_n + 2 D_t F_n + sum_(i+j=n) ((D_x G_i)(D_y F_j)-(D_y G_i)(D_x F_j)) = 0,

with the radial powers accounted for in each Cartesian derivative. Thus the expected nonlinear coefficient is (n-1)F_n-2D_tF_n. The independent implementation uses signed Laurent polynomials; any Kronecker encoding uses a stride greater than the entire angular support of a product, preventing aliasing between angular and logarithmic degrees.
