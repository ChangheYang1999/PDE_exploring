# Independent algebra checks

The squared output distance is affine in the squared input distance
when the two radii are fixed. Its endpoint values are the squared
radial difference and squared radial sum. The target is concave, so
checking those two endpoints has the correct inequality direction.
Antipodal equal radii attain the asserted constant, including in a
one-dimensional Hilbert space. The zero-radius case is handled before
dividing by rs. The complex output is a conjugate radial-power map,
so its full seminorm is c_alpha times the exact radial-power seminorm;
using a zero endpoint would not attain that norm. The input estimate
is an upper bound obtained by a Lipschitz composition, not an asserted
exact seminorm of its third angular harmonic.
