## Checks for V214 (proof 209)

1. Eigenvalue signs and the resonance list. PASS.
At the source, DV(P) = B = diag(A, mu) with both entries positive (proof 15: w' = d_x V_1 in [10, 51/5], mu = d_y V_2 near 1; CONVENTIONS S6.3). The value -A belongs to the origin saddle diag(-A, D), not to P. So B lies in the Poincare domain. For a monomial X1^m X2^n e_j of degree d = m + n, the homological operator P -> DP BX - BP multiplies the coefficient by m A + n mu - lambda_j, with lambda_1 = A and lambda_2 = mu. I verified this directly: (DP BX)_j = (m A + n mu) X1^m X2^n. The resonances to exclude for 2 <= d <= 11 are m A + n mu = lambda_j.
For j = 2: m A + n mu >= (m+n) mu >= 2 mu > mu, using A > mu. No resonance.
For j = 1: if m >= 2 then m A >= 2A > A. If m = 1 then n mu = 0, which forces n = 0 and degree 1, excluded. If m = 0 the condition is n mu = A, i.e. n = A/mu. So the only candidates are pure y^n e_1 terms, and 10 mu < A < 11 mu excludes all of them because A/mu is not an integer. In fact A/mu lies in (10.150725472, 10.150725473). The argument excludes resonances of every degree, as the proof says. The claim follows from 10 < A/mu < 11 exactly as stated.

2. Finite-jet removal algebra. PASS.
With Y = X + P_d(X) and remaining field BX + N(X), N of order d, the transformed field is (I + DP_d)(BX + N) expressed in Y. Substituting X = Y - P_d(Y) + O(|Y|^(2d-1)) changes BX by -B P_d(Y) and changes N and DP_d BX only at degree >= 2d - 1 >= d + 1. So the degree-d part is N_d + DP_d BY - B P_d, which is what the proof states. Dividing the coefficients of -N_d by the nonzero denominators solves the homological equation. Composing d = 2..11 gives a polynomial local diffeomorphism Psi_0 tangent to the identity, and W = BZ + R with R smooth and with vanishing 11-jet. Taylor's theorem gives D^l R = O(|Z|^(12-l)) for l <= 12 on a fixed closed ball. Equivariance holds because B is diagonal and commutes with (s,y) -> (s,-y), so the homological operator preserves the reflection class.

3. Backward-flow contraction and flow-derivative bounds (7)-(8). PASS.
Since DW(0) = B has symmetric part >= mu I and mu > 0.9999999 > mu' = 99/100, a closed ball exists on which sym DW >= mu' I. Then Z.W(Z) = integral_0^1 Z.DW(tZ)Z dt >= mu'|Z|^2, so |Y_t| decreases at rate mu', the ball is invariant, and (7) holds. For DY_t, d/dt |DY_t v|^2 = -2 (DY_t v).DW(Y_t)(DY_t v) <= -2 mu'|DY_t v|^2. For k >= 2, the D^k Y_t equation has linear part -DW(Y_t) acting on the output index, so its propagator has norm <= exp(-mu'(t-s)). The forcing has the form D^j W(Y_t)[D^(i_1)Y_t, ..., D^(i_j)Y_t] with j >= 2 and every i < k, so by induction it is bounded by C exp(-2 mu' t). The initial datum is 0. Variation of constants gives C exp(-mu' t)/mu', which is (8). The claim is correctly only exp(-mu' t) for every k, not exp(-k mu' t), and only this weaker bound is used later.

4. Exponent bookkeeping for H and all its derivatives (the "stronger gap" question). PASS.
The naive product form D[exp(Bt)Y_t] = exp(Bt)DY_t has majorant exp((A - mu')t), which diverges. If one tried to pass to the limit in that form, a larger gap would indeed seem necessary. The proof does not do this. It differentiates the integral form (9), H = Z - integral exp(Bt) R(Y_t) dt. By Faa di Bruno, a k-th derivative of R(Y_t(Z)) is a sum of D^l R(Y_t)[D^(i_1)Y_t, ..., D^(i_l)Y_t] with i_1 + ... + i_l = k. For l <= 12, |D^l R(Y_t)| <= C|Y_t|^(12-l) <= C exp(-(12-l) mu' t), and the l flow factors give exp(-l mu' t). The total is exp(-12 mu' t), independent of k. For l > 12 the l flow factors alone give exp(-l mu' t) <= exp(-12 mu' t). Multiplication by exp(Bt) costs exp(At). So every derivative has the integrable majorant C_k exp(-(12 mu' - A)t), with 12 mu' - A > 297/25 - 51/5 = 42/25 > 0. My exact recheck gives 12(99/100) - A_max = 1.72927.... The integrals converge uniformly in C^k for every k, so H is C^infinity, not merely C^2. The extra |Y_t|^(12-l) factor is exactly what offsets the exp(At) growth. The only reason a stronger gap would be needed is if some flow derivative grew, as for a saddle, and a source's backward flow contracts in every direction. Retaining the vanishing powers gives H - Z = O(|Z|^12), DH - I = O(|Z|^11) and D^2 H = O(|Z|^10), as stated. The limit form of (9) follows by integrating d/dt[exp(Bt)Y_t] = -exp(Bt)R(Y_t). D^k of the limit form also converges, because it equals D^k of the partial integrals.

5. Conjugacy identity and composition. PASS.
For small s and Z in a smaller ball, Y_t(Flow_s Z) = Y_(t-s)(Z) for t >= s. Hence exp(Bt)Y_t(Flow_s Z) = exp(Bs) exp(B(t-s)) Y_(t-s)(Z), which tends to exp(Bs)H(Z). Differentiating at s = 0 gives DH W = B H. With DPsi_0 V = W o Psi_0, the chain rule gives DPsi V = DH(Psi_0) W(Psi_0) = B H(Psi_0) = B Psi, which is (2). Reflection equivariance passes through the backward flow and the integral.

Proof 209 correctly does not use it ("The finite global C6 knot regularity is not being substituted ..."). The stream (2) of proof 15 is built from I_n and J_n, which satisfy the constant-coefficient ODEs (1) of proof 15 with forcings H_(n-1) and H_n. 8. Cutoff extension and global inverse. PASS.
Phi_delta - id = chi(X/delta)(Psi - X) is O(delta^2) in sup. Its derivative is delta^(-1) Dchi O(delta^2) + chi O(delta) = O(delta), and its second derivative is O(1). The Holder bound comes from splitting at |x - y| = delta, with sup O(delta) and Lipschitz constant O(1). For small delta, Lip(Phi_delta - id) < 1 on the convex R^2, so X = Y - w(X) has a unique fixed point and Phi_delta is a global diffeomorphism. Phi_delta = Psi on B_(delta/2) and = id outside B_delta, so V_delta = DPsi^(-1) B Psi = V on B_(delta/2) and V_delta = BX outside B_delta.

9. Norm transfer of C_delta on X_alpha. PASS.
The L2 bound is (sup det DPhi)^(1/2) <= 1 + C delta, the sup norm is preserved, and [h o Phi^(-1)]_alpha <= Lip(Phi^(-1))^alpha [h]_alpha <= (1 - C delta)^(-alpha)[h]_alpha. The inverse is analogous. The proof correctly warns that this does not make C_delta - I small in operator norm.

10. Exact maximal-domain conjugation (5). PASS.
With h = u o Phi, grad h(X) = DPhi(X)^T grad u(Phi X). So V_delta.grad h(X) = (DPhi V_delta)(X).grad u(Phi X) = (B Phi X).grad u(Phi X), that is C_delta(V_delta.grad h) = BY.grad(C_delta h). For distributions, the pushforward (T o Phi^(-1), phi) = (T, (phi o Phi) det DPhi) agrees with composition on functions. Both sides of the identity are continuous in D' under mollification of the bounded continuous h, because V_delta is smooth. Since C_delta and its inverse are bounded on X_alpha, the two maximal transport domains correspond exactly, with equivalent graph norms. This D_alpha is the same set as in proof 208.

12. The weak pullback identity (8) and the output formula (9). PASS.

13. Homogeneous H1 realization and the projection identity (11). PASS.
P_vec(e_k f) is in L2 and curl-free (its Fourier transform is parallel to zeta), so it is the gradient of an H1_loc function q, unique up to a constant. 18. Parity. PASS, subject to Remark 4.

## Remarks

1. Eigenvalue signs. B = diag(+A, +mu). The brief's "-A?" refers to the origin saddle. At P the only possible resonances are m A + n mu = lambda_j with lambda_j in {A, mu}, and the only one not excluded by sign or size is the pure y^n e_1 family, n = A/mu. team message 64 says the limit "converges with at least two derivatives". The proof in fact gives C^infinity convergence from the single condition 12 mu' > A (check 4). No stronger gap is needed, because the backward flow at a source contracts in every direction, so no flow derivative grows.

2. Which degrees carry the argument. The degree-10 removal is the essential step. Its denominator 10 mu - A, about -0.1507, is the near-resonance and the smallest of the 150. With jets removed only through degree 9, convergence would need 10 mu' > A, which is impossible for mu' < 1 since A > 10.15. Degree 11 is a margin, not a necessity: 11 mu' = 10.89 > A already. So the load-bearing spectral fact is the strict inequality 10 mu < A, certified with margin 0.1507. It might be worth saying this explicitly so that later uses, for example a perturbed background, keep 10 mu < A in view.

3. "Analytic disk" wording. The check script certifies only the knot-span geometry, i.e. a disk of radius 1/1000 inside one log-span. The word "analytic" in check.json, in VERIFICATION_RECORD V214 and in team message 65 is correct, but it is justified by the proof 15 structure (finitely many sin((2j+1)theta) modes times r^3 times log-polynomials, and a stream built from constant-coefficient ODEs with polynomial forcing on the span), not by the script. The PROOF body says "smooth radial and angular functions" and proves only smoothness, which is all it needs. A one-line pointer to proof 15 (1)-(2) would close this.

4. Cutoff parity. Both proof 209 ("smooth cutoff chi supported in B1 and equal 1 on B_(1/2)") and the definition in proof 210 omit that chi is radial, or at least even in y. This is needed for the equivariance of Phi_delta and for the parity of chi_delta E_delta and H_delta. Proof 210 later calls it "the radial cutoff". This should be stated in the definitions. The fix is trivial and nothing else changes.

5. Named input. check.py hard-codes the mu box rather than reading it from proof 15's result JSON. The values match the proof 15 PROOF statement (line 118) exactly and are labelled as an input, so this is acceptable. A future replay could also assert it against the certificate file.

6. Neumann series. team message 65 and the brief describe the commutator as coming from a Neumann series. Proof 210 instead uses the exact identity (11) together with the a priori membership bound (10), which avoids any solvability question. If the Neumann route is preferred, it is also valid: ||P_vec(G - I)||_(X->X) <= C_P C ||G - I||_(C^alpha) = O(delta^(1-alpha)) < 1, and the unique X_alpha solution coincides with the actual w because w solves (11) and lies in X_alpha.

7. Meaning of "actual velocity". U[h] here is the L2 Fourier realization, as proof 210 states. For L2 inputs, the canonical kernel velocity of CONVENTIONS S2.3 (far subtraction K(X - Y) - K(-Y) about the original origin) differs from it by a constant vector. The U2 constant vanishes for odd-y inputs. The U1 constant, -integral_(|Y|>1) K_1(-Y) h(Y) dY, needs evenness in x about the origin to vanish, and the auxiliary source class imposes only odd-y. This constant is bounded by C ||h||_2 (K_1 is in L2 off the unit disk) and multiplies rho0_x(P+X) = O(|X|). After localization it would be a further rank-one perturbation of size O(delta^(1-alpha)), harmless for the inverse. Still, "equal to the actual operator on B_(delta/2)" should be read with the L2 velocity, which coincides with the canonical one for globally even-x, odd-y L2 inputs. This matters only when the source inverse is patched into the global problem, which is declared open.

8. Alpha dependence. For each fixed alpha < 1 there is a delta_0(alpha), and the inverse bound is uniform as delta -> 0 for that alpha. Nothing is uniform as alpha -> 1, since delta^(1-alpha) -> 1 there. "For every alpha < 1" in V215 is meant, and correct, pointwise in alpha.

9. The generality paragraph of proof 210 lists a smooth source field and a C2 background as separate data. In the application they are linked by V = X/k + U[rho0], and on the 1/1000 disk both are analytic, so nothing is lost. The cited spectral conditions are proof 209's specific numerical windows, which are narrower than general Poincare-domain non-resonance. This is a restriction, not an overreach.
