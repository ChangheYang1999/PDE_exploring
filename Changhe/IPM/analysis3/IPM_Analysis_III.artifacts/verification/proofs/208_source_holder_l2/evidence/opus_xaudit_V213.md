## Checks

0. Semigroup, formula (4) and hypotheses. PASS.
D_t f(X) = f(e^(Bt)X) satisfies d/dt D_t = D_t (BX.grad) = (BX.grad) D_t, because B commutes with e^(Bt). Its Fourier form is (D_t f)^(zeta) = e^(-(A+mu)t) fhat(e^(-Bt)zeta). Conjugation gives m(D) D_t = D_t m(e^(Bt)D). So S_t = e^(-t) D_t Q_t solves d/dt S_t = L0 S_t exactly when dQ_t/dt = -g M(e^(Bt)zeta) Q_t. Here M(e^(Bt)zeta) = e^(2(A-mu)t)xi^2/(e^(2(A-mu)t)xi^2+eta^2). Integrating gives (2) with a = g/(A-mu). The semigroup law is the telescoping identity Q_t(e^(Bs)zeta) Q_s(zeta) = Q_(t+s)(zeta), which I checked after dividing by e^(2 mu s). Evaluating Q_t at e^(-Bt)zeta gives e^(a mu t)|e^(-Bt)zeta|^a |zeta|^(-a), and this gives (4) with exponent a mu - 1 - A - mu. Since 0 <= Q_t <= 1 and ||D_t||_(L2) = e^(-(A+mu)t/2), (3) holds. I checked the generator identification. For f in the transport domain, (Q_t f - f)/t tends to -gMf by dominated convergence, since |dQ_t/dt| <= g. So the generator of S_t extends L0 on that domain. L0 there is itself a generator, as a bounded perturbation of a generator. A generator has no proper extension that is again a generator, so the two coincide. On the annulus, the right side of (4) is e^((a mu-1)t) |D|^(-a) D_t |D|^a, as claimed.

1. The dyadic sums and the Bernstein power. PASS, with a wording point (Remark 1).
Support. For t >= 0 we have e^(-At)|zeta| <= |e^(-Bt)zeta| <= e^(-mu t)|zeta|. So input annulus N and output annulus lambda interact only for log(lambda/N)/A <= t <= log(lambda/N)/mu, up to fixed shifts, and only if N <= C lambda. Output frequencies never decrease. The integrand vanishes off a bounded time interval, so no integrability at t = infinity is used.
Time integral. If a mu > 1, the integral of e^((a mu-1)t)(N/lambda)^a up to t_up = log(C lambda/N)/mu is at most C (N/lambda)^(a-(a mu-1)/mu) = C (N/lambda)^(1/mu). This is (6) and holds for every N <= C lambda, including N < 1. Bounding the Bochner integral in sup norm is legitimate: pair with L^1 test functions.
High input, 1 <= N <= C lambda. With (7), the block sum is lambda^(-1/mu) [f]_alpha sum N^(1/mu-alpha). This is a finite geometric sum. It is dominated by its top term (C lambda)^(1/mu-alpha) if and only if alpha < 1/mu. It is O(log lambda) at alpha = 1/mu and O(1) for alpha > 1/mu, which then gives only lambda^(-1/mu), weaker than lambda^(-alpha). So alpha < 1/mu is exactly the condition for the same-order gain lambda^(-alpha) from this branch.
Low input, N < 1. The kernel of Delta_N is N^2 phi(N.), with L^2 norm N ||phi||_2 in dimension 2, so (8) holds with the power N^(d/2) = N. Combined with (6), each block gives C lambda^(-1/mu) N^(1+1/mu) ||f||_2. The sum over dyadic N < 1 converges for every mu > 0 and every alpha. The resulting lambda^(-1/mu)||f||_2 is at most lambda^(-alpha)||f||_2 for lambda >= 2 because alpha < 1/mu. This is the only other place where alpha < 1/mu enters.
Reconciling team message 62 and 63. team message 62 states the condition from the dyadic sum, alpha < 1/mu. The theorem states 0 < alpha < min(1, 1/mu). The bound alpha < 1 comes from the classical Holder characterization (the derivative sum d sum_(lambda<=1/d) lambda^(1-alpha) = O(d^alpha) requires alpha < 1), not from the source dynamics. For mu > 1 the binding constraint would be alpha < 1/mu. For mu <= 1 it is alpha < 1. The certified box 0.99999997745 < mu < 0.99999997750 gives 1/mu > 1, so min(1, 1/mu) = 1 and team message 63's "every alpha < 1" is the specialization of team message 62's condition. The two notes are consistent.
Identification. Delta_lambda R0 f is the L^2 limit of sum_N Delta_lambda R0 Delta_N f, and the series is absolutely convergent in sup norm. So the uniform limit is Delta_lambda R0 f a.e., as stated. Blocks with N > C lambda vanish.
Reconstruction. ||R0 f||_inf is at most the low block (10) plus sum_(lambda>=2) C lambda^(-alpha)(...), which is finite. For d < 1, the split at lambda = 1/d gives O(d^alpha) from the derivative bound C lambda on enlarged kernels and from the supremum sum. The low output block is Lipschitz with constant C||R0 f||_2, because the gradient of its kernel is in L^2. The proof does not state this, but it is immediate (Remark 2). Hence ||R0 f||_X <= C(||f||_2 + [f]_alpha).

2. Maximal domain, two-sided inverse and uniqueness in X_alpha. PASS.
The L^2 maximal domain equals the generator domain of D_t. The quadrant charts give this. So does the direct weak argument D_t f - f = integral_0^t D_s(BX.grad f) ds for f in the maximal domain, obtained by pairing with D_t^* phi (Remark 5). Then R0 = -integral S_t dt is the two-sided L^2 inverse on that domain. In X_alpha: if f is in X_alpha, then h = R0 f is in X_alpha by Check 1. The equation L0 h = f holds in L^2. Hence BX.grad h = f + h + gMh is in X_alpha by (11), so h is in D_alpha and L0 R0 = I on X_alpha. If h is in D_alpha, then BX.grad h is in X_alpha, which lies in L^2, so h is in the L^2 maximal domain and R0 L0 h = h. Thus R0 maps X_alpha onto D_alpha and is a two-sided inverse there. The kernel is trivial: a homogeneous solution in D_alpha lies in the L^2 domain and is therefore 0. Bounded M on X_alpha shows that D_alpha is also {h in X_alpha : L0 h in X_alpha}, the maximal X_alpha domain of L0. Closedness follows either from the proof's argument (X_alpha convergence implies L^2 and distributional convergence) or because a bijection with bounded inverse is closed. No density of smooth functions in the large Holder norm is used, which is correct and necessary. The X_alpha realization is the part of the L^2 operator in X_alpha, so the selected inverse is the same as in proof 26.

4. Riesz multipliers on X_alpha and the coefficient variation. PASS.
High output blocks, lambda >= 2. tilde-Delta_lambda M is a rescaled fixed Schwartz kernel, because M is homogeneous of degree 0 and smooth on annuli. Its L^1 norm is uniform, so ||Delta_lambda M f||_inf <= C ||Delta_lambda f||_inf <= C lambda^(-alpha)[f]_alpha by (7). Low block, the delicate part. The symbol chi_low(zeta) M(zeta) is bounded with compact support, hence in L^2, so its kernel is in L^2 and ||Delta_low M f||_inf <= C||f||_2. The same holds for its gradient. This is exactly where the L^2 component substitutes for the failure of Riesz transforms on L^infinity. Without the L^2 term, M is not even defined on C^alpha_b (for example on constants). ||Mf||_2 <= ||f||_2. The block reconstruction of Check 1 then gives (11). U1 (symbol xi eta/|zeta|^2) and U2 = -M are treated in the same way. The sign conventions agree with CONVENTIONS S2.1 and proof 01 (hat U_1 = xi_1 xi_2 |xi|^(-2) hat h, U_2 symbol -xi_1^2/|xi|^2). Splitting differences at delta gives [b_(j,delta)]_alpha <= max(C delta^(1-alpha), 2C delta^(1-alpha)). This is (12). The product rule |bf(X) - bf(X')| <= |b||f(X)-f(X')| + |f||b(X)-b(X')| then gives ||b f||_X <= C delta ||f||_X + C delta^(1-alpha)||f||_inf <= C delta^(1-alpha)||f||_X for delta <= 1. With (11), ||E_delta|| <= C delta^(1-alpha). The factorization (I + E_delta R0) L0 = L0 + E_delta on D_alpha uses R0 L0 = I there. 5. The strain counterexample. PASS.
H = x^2 y beta(r) vanishes near 0, so CONVENTIONS S3.2 applies without the local d_y h(0) term. c[H] = (1/pi) integral r beta(r) dr times integral_0^(2pi) cos^2 sin sin3 dtheta. The angular integral is pi/4: sin t sin 3t = (cos 2t - cos 4t)/2, cos^2 t = (1 + cos 2t)/2, so the integrand is (1+cos 2t)(cos 2t - cos 4t)/4, and only (1/4) integral cos^2 2t dt = pi/4 survives. So c[H] = (1/4) integral_1^2 r beta(r) dr > 0. Scaling X = eps Y gives dX = eps^2 dY and r^(-3) = eps^(-3)|Y|^(-3), so c[h_eps] = eps^(alpha-1) c[H]. The norms in (13) are correct: the sup norm scales by eps^alpha, the alpha seminorm is invariant, and the L^2 norm scales by eps^(alpha+1) in dimension 2. Each h_eps is smooth, compactly supported, even in x and odd in y, and vanishes near 0, so J(h_eps) = 0. Hence c[h_eps]/||h_eps||_X tends to infinity for every alpha < 1. The full strain functional is unbounded in the X_alpha norm, and (c[h]/3)G is not a bounded operator on X_alpha (Remark 6 on what this does and does not show).

## Remarks

1. "Converge" for the high sum. Both the proof ("controlled by its largest term because alpha < 1/mu", which is correct) and evidence/check.json ("Both dyadic sums converge for alpha<1/mu") describe the high sum loosely. That sum is finite for each lambda. What alpha < 1/mu buys is domination by the top term, hence the gain lambda^(-alpha). The low sum converges for every alpha, and alpha < 1/mu is used there only to absorb lambda^(-1/mu) into lambda^(-alpha). Suggested wording: "the high sum is O(lambda^(1/mu-alpha)) because alpha < 1/mu; the low sum converges for all alpha".

2. Low block in the Holder reconstruction. After (10), and again for M after (11), the proof treats only the high blocks in the difference estimate. The low block is Lipschitz with constant C||f||_2, because i zeta chi_low(zeta) (times M if present) is a bounded compactly supported symbol with an L^2 kernel. One sentence would close this. It is not a gap.

3. The sup norm is redundant in the X_alpha norm. In two dimensions, averaging over the unit ball gives |f(X)| <= pi^(-1/2)||f||_2 + [f]_alpha, so ||f||_2 + [f]_alpha is an equivalent norm. This explains why (9) and (10) never use ||f||_inf. The sup norm is used only in the coefficient product estimate, where it may be replaced by this bound.

4. Attribution of a mu < A+1. The proof says the condition came "from proof 26's higher-order bounds". In proof 26 it was also used in the low-input estimate (9) of that proof ("Since the exponent is negative"), which enters part (a) as well. So proof 208 removes the upper condition from the low-order theorem itself, a small genuine strengthening that the wording understates. team message 63's formulation ("unnecessary for this low-order claim") is accurate.

5. Domain identification. The quadrant-chart argument is correct. A shorter self-contained route is the weak identity D_t f - f = integral_0^t D_s(BX.grad f) ds for f in the maximal domain, obtained by pairing with D_t^* phi. It shows that the maximal domain equals the generator domain of D_t without charts or a discussion of the axes. This is optional.

6. Reading of "actual velocity" and of the strain conclusion. (a) The coupling equality inside B_(delta/2) holds with U defined by the L^2 Fourier multipliers, as the proof defines it. CONVENTIONS S2.3's canonical velocity has a far subtraction at the global origin, and for L^2 data it differs from the multiplier velocity by the constant vector integral_(|Y|>1) K(-Y) h(Y) dY. This converges because K is O(|Y|^(-2)), which is in L^2 away from 0. It vanishes for global parity-class data (sin 2theta odd in x, cos 2theta even, against h even in x and odd in y), so the identification holds there, as in the V207 and V211 audits. For whole-plane inputs without parity, the statement is about the multiplier velocity. (b) The counterexample proves unboundedness of c in the X_alpha norm, which is exactly what is claimed. It does not by itself show that c is unbounded relative to the D_alpha graph norm of the frozen source operator. In source coordinates the packets sit at X0 = (-p, 0), and B X0.grad h_eps has sup norm of order eps^(alpha-1). That question is not claimed, and the proof's wording ("merely by citing the frozen source theorem", "additional origin control or a separately supplied scalar is needed") is appropriately hedged. Also, c is defined only on inputs with sufficient origin regularity, not on all of X_alpha. "Unbounded" should be read on that natural domain, which contains every h_eps.

7. Logical "so" in the modal-source sentence. "These exact rational bounds imply a mu>1, so every 0<alpha<1 is covered" gives the wrong reason. a mu > 1 is the hypothesis of the theorem. Coverage of every alpha < 1 comes from mu < 1, which makes min(1, 1/mu) = 1. Both facts are displayed, so nothing is missing, but the sentence should cite mu < 1 for the coverage.

8. Constants. The X_alpha constant blows up as alpha tends to 0 or 1, and in general as alpha tends to 1/mu or a mu tends to 1. It also depends on the dyadic partition. This agrees with "qualitative Holder constant". The admissible delta in the localized statement is likewise qualitative. Neither is certified numerically, and neither is claimed.
