# Precise local regularity scope for the axis identity

Read this with PROOF.md. The submitted proof hash is preserved.

For a precise sufficient test class in the statement, assume that h has the required global parity and a canonical velocity, that c[h] is finite, that h=x^4 H on B(0,r_chi) with H in C1 on that disk, and that U[h] is in C1 there. The fixed modal background and its chart derivative have the regularity already stated in the accepted dependencies. These explicit hypotheses suffice for all coefficient limits and derivatives in equations (2) through (8). The more general phrase 'enough local regularity' is not needed as an additional, unspecified assumption.

For this C1 velocity class, equation (8) and odd parity imply axis(R_h)=o(y) at the origin. The stronger O(y^3) statement requires the smooth odd expansions of the test velocity as well as the background. It holds for the exact Gaussian of proof 241 and for smooth test velocities with the corresponding third derivatives bounded near the origin. No O(y^3) assertion for an arbitrary merely C1 test velocity is intended.

The density divisibility is local on the zero-cutoff disk. No global high-domain membership is inferred from it. The Gaussian's global membership is an independently established input, V283. The additional term outside this disk is handled in the full formula (1); it is not discarded by this local identity.
