# Exact angular bandwidth of the S1 core images

## Statement

Let the background density have odd sine frequencies2j+1 with0<=j<=J-1, and let its canonical polar velocity divided by r have even frequencies2n with1<=n<=J. Let a finite S1 remainder basis consist of columns

 h=r^3 b(log r) p(theta)(cos(2m theta)-(-1)^m),
 p=cos(theta)^2 sin(theta), 1<=m<=M-1.

The radial coefficients may be arbitrary functions for which the operator is defined; radial joins and cutoff functions do not change angular bandwidth. For the core operator S1=T_R+C_R, with exact axis subtraction and the radial origin-strain cutoff of topics92 and176, every image has only odd sine indices

 0<=N<=J+M, meaning physical frequency2N+1.             (1)

Consequently J+M+1 raw odd-sine coefficient slots, and J+M-1 quotient slots after exact division by cos(theta)^4, suffice. This is an upper bound on support, not a claim that the top coefficient is always nonzero.

For the actual finite background J=261. Thus raw slot counts264,265,266 suffice for M=2,3,4, respectively. The current S1 implementation uses531,533,535 raw slots. That padding is conservative and drops no mode, but its upper half consists of exact zeros before floating quotient division. This distinction matters because the padded least-squares inverse introduces padding-dependent coefficient errors, as proved in topics183 and185.

Statement(1) is restricted to S1. The compensated full L_red image includes the full-band KP column and can have indices as high as2J-1=521 for this trial. The smaller S1 count must not be substituted blindly into that branch.

## Proof

Multiplication of p=(sin(theta)+sin(3theta))/4 by cos(2m theta) gives only odd sine frequencies with index j<=m+1<=M. The m=0 partner does not enlarge this bound. Differentiation in r or theta leaves the maximal polar angular frequency unchanged.

The canonical equation for the stream function is -Delta psi=partial_x h. The Cartesian derivative shifts an odd sine frequency2j+1 to even frequencies2j and2j+2. Solving the radial modal equations does not create new angular frequencies. Hence the polar velocity U[h]/r has even frequencies2n with n<=M+1. Canonical conditions exclude extra homogeneous angular modes not generated by the density.

In the transport U[rho_0].grad h, the background polar velocity has n<=J and h has j<=M. Product-to-sum identities give frequencies2j+1+2n and their signed differences. The plus frequency has index N=j+n<=J+M. A negative difference, after converting sin(-f)=-sin(f), has index n-j-1, which obeys the same bound. The dilation and scalar multiplication terms stay within the original input bandwidth.

In U[h].grad rho_0, the density has j<=J-1 and the input velocity has n<=M+1. Thus again N<=j+n<=J+M. The radial origin-strain correction uses the background gradient and a fixed linear strain. In polar coordinates that strain has frequency2, so its index is at mostJ. A pure dilation correction has index at mostJ-1. Neither enlarges(1).

Exact vertical-axis subtraction removes E gamma=r^3p gamma(t), which has only indices0 and1. Therefore the core remainder image still obeys(1). Its exact vertical cofactor and reflection parity make it divisible by cos(theta)^4, by the core mapping theorem. Multiplication by cos(theta)^4 raises the highest odd sine index by2 with nonzero leading coefficient1/16. Hence a nonzero quotient has largest index at mostJ+M-2, proving the claimed quotient slot count.

For the compensated full operator, KP has the same density bandwidth as the background, namely j<=J-1, and its velocity has n<=J. The same product calculation gives index at most2J-1. This proves the scope restriction.

## Code audit and verification

The numerics code's addsin function stores a physical sine frequency f as index(f-1)//2. Its all-mode branch sets NMAX=2*T.Mj+2*Mh+4 and nm=NMAX+1; T.Mj=T.Nf=261. This is a safe overestimate, but the comment calling NMAX the highest image mode conflates the support calculation with an overpadded allocation. MODE=S1 sets the KP image to zero and keeps only remainder columns formed from m=0 partners and1<=m<Mh, exactly as assumed above. The origin cutoff is radial.

The companion exact integer script enumerates every signed sum/difference index allowed by the two products, the dilation, strain and axis-subtraction pieces. It checks(1) for the current M values and several generic J,M values, and records the source hashes. This is an algebraic bandwidth audit. It does not test the interval Green values or certify any finite-section matrix. Cutting exact zero raw modes before division preserves the true image; discarding a nonzero raw mode would require a separate projection or tail estimate.

Dependencies: the canonical polar modal equation, exact product-to-sum identities, the S1 core axis-subtraction definition, and topics183,185 for the independently established padded division errors.
