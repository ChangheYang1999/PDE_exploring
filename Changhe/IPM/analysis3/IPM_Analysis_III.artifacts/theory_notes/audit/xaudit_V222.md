## Verdict

PASS WITH REMARKS. I found no mathematical gap. The far rate of F0, the polar integral and both directions of the iff at gamma = 4k are correct, and unweighted L^2 does fail. The bound ||c||_(Y*) <= 4/pi is correct. It uses only the E2 part of the norm, and it is the p = 2 case of the proof 200 bound (4/pi)max(1,1/(p+alpha-1)), which proof 203 also states. The three local norm comparisons are correct: the multiplier bound on E2, E2 versus C^alpha on a vertical strip, and C^alpha versus E2 for supports with |x| >= a > 0. The proofs of boundedness of K_o = chi_o R_o eta_o and K_s = u_+ + u_+(-x,y) are complete. Each local inverse gets an input in its own space, and its output is used only after an output cutoff, so neither inverse is assumed to preserve L^2(w_gamma). Odd-y parity of u_+ follows from the reflection equivariance recorded in topics209 and210 together with uniqueness. The source-supported strain bound is a correct Cauchy-Schwarz estimate, and its constant is in fact exactly the L^2(w_gamma) dual norm of the localized functional. The proof makes no global statement. The remarks concern which origin operator R_o denotes, one loose phrase ("extended with the required parities") in the support comparison, the fact that the L^2(w_gamma) part of the input norm is never used in statements 1, 3 and 4, the interpretive character of statement 5, and minor wording.

## Checks

1. Completeness of E2 and Y. PASS.
A Cauchy sequence in E2 is uniformly Cauchy. Its limit is bounded, continuous, even in x, odd in y and zero on x = 0. For fixed pairs of points the difference quotients converge pointwise, so the seminorm bounds and convergence in seminorm pass to the limit by the usual epsilon/3 argument. For Y, the E2 limit h and the L^2(w_gamma) limit g agree a.e. Uniform convergence on a compact set implies L^2 convergence there. L^2(w_gamma) convergence on a compact set implies unweighted L^2 convergence there, because w_gamma >= (1+R^2)^(-gamma/2) on B_R when gamma >= 0. The proof states exactly this.

2. Far rate of F0. PASS.
Proof 117 (4) gives F/r^3 = exp(alpha_1 tau)S(theta) + O(exp((3k-5)tau)) with alpha_1 = 2k-4 and tau = log r - t_+. Since exp(alpha_1 tau) = R_+^(4-2k) r^(2k-4), where R_+ = exp(t_+) is proof 117's radius and not the source inverse, this is F0 = r^(2k-1)S_0(theta) + O(r^(3k-2)) with S_0 = R_+^(4-2k)S. The remainder is uniform in theta because the angular expansion is finite. The remainder is lower order because (3k-2)-(2k-1) = k-1 < 0. This agrees with proof 39 (9) (B = O(r^(2k-4)), F = x^2 y B = O(r^(2k-1))) and with the heuristic count: the drift cancels the leading r^k Theta exactly because ell k = 1, and U[rho0].grad rho0 ~ r^k r^(k-1).

3. Nonvanishing of S_0. PASS.
V120 certifies the leading remainder coefficient of e_rem as a positive interval (about 4.577e9). By proof 117 that coefficient is exp(-2 alpha_1 t_+)E_S with E_S = M H(Q_S), where H is a weighted angular L^2 norm of sin(theta)Q_S. E_S > 0 forces Q_S to be nonzero, hence B_S is nonconstant, hence S = cos^2 sin B_S is nonzero, hence ||S_0||_(L^2(dtheta)) > 0. The proof relies on this certified input and correctly says it adds no new numerical claim. As a consistency check, proof 117 (5) with radial weight r^(-5/4) gives the t-density rate 4k-5/4. Replacing 5/4 by gamma gives the rate 4k-gamma, which is integrable at +infinity iff gamma > 4k, the same threshold.

4. Both directions of the iff gamma > 4k, and unweighted L^2 failure. PASS.
Squaring, |F0|^2 = r^(4k-2)S_0^2 + O(r^(5k-3)) + O(r^(6k-4)) uniformly in theta. So integral |F0|^2 dtheta = r^(4k-2)(||S_0||_2^2 + O(r^(k-1))), which lies between (1/2)||S_0||^2 r^(4k-2) and 2||S_0||^2 r^(4k-2) for r >= r_1. For r >= 1, 2^(-|gamma|/2) r^(-gamma) <= w_gamma <= 2^(|gamma|/2) r^(-gamma) for every real gamma. With dX = r dr dtheta, the tail integral is comparable, above and below, to integral_(r_1)^infinity r^(4k-1-gamma) dr. It is finite iff 4k-1-gamma < -1, that is gamma > 4k. The upper bound alone needs only |F0| <= C r^(2k-1). The lower bound needs ||S_0|| > 0 (Check 3). On B_(r_1), F0 is bounded (Check 5) and w_gamma is bounded, so this part is finite. Unweighted L^2 is gamma = 0 <= 4k, so it fails. Concretely, |F0|^2 ~ r^(-1.2826) decays more slowly than r^(-2). The iff ranges over all real gamma, although Y is defined only for gamma > 4k. That is how statement 2 reads, and it is correct.

5. F0 in E2 for every alpha in (0,1). PASS.
Parity holds, and F0(0,y) = 0 because F0 = x^2 y B (proof 39 (5)). For the x seminorm: on a line y = 0, F0 = 0 by oddness. On a line y != 0, which avoids the origin, F0 is C^1 in x across the finitely many radial joins, with |partial_x F0| bounded globally: O(r^4) near 0, O(r^(2k-2)) at infinity, finite on compact annuli. A bounded function of one variable with Lipschitz constant L has alpha seminorm at most max(L, 2||.||_inf). For the y seminorm, on each line x != 0 the quotient equals |H(x,y)-H(x,y')|/|y-y'|^alpha with H = yB. H is bounded (O(r^3), O(r^(2k-3))) and so is partial_y H = B + y partial_y B (O(r^2), O(r^(2k-4))). The conversion from cylinder derivatives (r partial_r, partial_theta) to Cartesian derivatives costs exactly r^(-1), as stated. No regularity of F0 at the origin itself is needed, because neither seminorm uses a line through the origin with a nonzero quotient. This is consistent with proof 39's remark that C5 regularity at 0 is not asserted.

6. Strain bound ||c||_(Y*) <= 4/pi. PASS.
Since h(x,0) = 0 by oddness, the y seminorm with y' = 0 gives |h(x,y)| <= [h]_(y,2)|x|^2|y|^alpha <= [h]_(y,2) r^(2+alpha). With dX = r dr dtheta, the integrand of (1/pi) integral |sin 3theta| r^(-3)|h| dX is at most (1/pi)[h]_(y,2) r^alpha |sin 3theta| on r < 1 and (1/pi)||h||_inf r^(-2)|sin 3theta| on r >= 1. Also integral_0^(2pi)|sin 3theta| dtheta = (1/3)(6)(2) = 4, integral_0^1 r^alpha dr = 1/(1+alpha) and integral_1^infinity r^(-2) dr = 1. Hence |c[h]| <= (4/pi)(||h||_inf + [h]_(y,2)/(1+alpha)) <= (4/pi)||h||_(E2) <= (4/pi)||h||_Y. This is exactly the p = 2 case of proof 200 (3), (4/pi)max(1,1/(p+alpha-1)), where p+alpha-1 = 1+alpha > 1. Proof 203 states the same reduction explicitly. The identification with the canonical derivative DU(0) uses proof 201 with p = 2, beta = 2+alpha > 1, gamma = min(beta,2) = 2, and p = 2 is inside the allowed range 1 <= p <= 2. The L^2(w_gamma) part is not used, and it could not replace the E2 part. Proof 208's packets h_eps = eps^alpha H(X/eps) have ||h_eps||_(L^2(w)) <= eps^(1+alpha)||H||_2 -> 0 while c[h_eps] = eps^(alpha-1)c[H] -> infinity. Consistently, [h_eps]_(y,2) = eps^(-2)[H]_(y,2), so the E2 bound is not contradicted.

7. Multiplier bound of a smooth compact cutoff on E2 and on L^2(w_gamma). PASS.
Write eta h(X) - eta h(X') = eta(X)(h(X)-h(X')) + h(X')(eta(X)-eta(X')). On horizontal pairs this gives [eta h]_x <= ||eta||_inf [h]_x + ||h||_inf max(2||eta||_inf, ||D eta||_inf). On vertical pairs, the first term gives ||eta||_inf [h]_(y,2)|x|^2|y-y'|^alpha. For the second term, take supp eta in B_R. If |y-y'| <= 1 and eta(x,y) != eta(x,y'), one point lies in B_R, so |y|,|y'| <= R+1. Then |h(x,y')||eta(x,y)-eta(x,y')| <= [h]_(y,2)|x|^2(R+1)^alpha ||D eta||_inf |y-y'|^alpha. If |y-y'| > 1, use the mirror identity eta(X')(h(X)-h(X')) + h(X)(eta(X)-eta(X')) with X on supp eta (if neither point is on the support, the difference is 0). Then |h(X)| <= [h]_(y,2)|x|^2 R^alpha and |eta(X)-eta(X')| <= 2||eta||_inf |y-y'|^alpha. Both identities are algebraically correct. The ||eta||_inf bound for the first term holds in both orientations. Parity and the axis condition are preserved because a radial eta is even in x and in y. The bound ||eta h||_(L^2(w)) <= ||eta||_(L^2(w))||h||_inf is immediate.

8. E2 versus C^alpha near the source, and C^alpha versus E2 away from x = 0. PASS.
(a) On the strip |x'| <= R (the proof calls it a "box", but the estimate holds on the whole strip), |h(X)-h(X')| <= [h]_x|x-x'|^alpha + [h]_(y,2)|x'|^2|y-y'|^alpha <= (1+R^2)||h||_(E2)|X-X'|^alpha, with the vertical leg taken at the strip point. After a smooth compact cutoff supported in the strip this gives a global C^alpha bound, because the case with one point outside the strip is handled by the cutoff difference and ||h||_inf. Compact support gives ||eta_+ f||_2 <= ||eta_+||_2||f||_inf. Translation by P_+ is an isometry of C^alpha_b and of L^2. Hence ||(eta_+ f)(.+P_+)||_(X_alpha) <= C||f||_(E2) in the norm ||.||_2 + ||.||_inf + [.]_alpha of proof 210.
(b) If g is C^alpha, supported in K with K contained in {x >= a > 0}, and odd in y, then g + g(-x,y) is in E2. On every vertical line at most one of the two terms is nonzero and |x| >= a there, so [.]_(y,2) <= a^(-2)[g]_alpha. Also [.]_x <= 2[g]_alpha, the sup norm doubles, the axis value is 0, and ||.||_(L^2(w)) <= 2||g||_2. See Remark 2 for the wording about parity.

9. Boundedness of K_o = chi_o R_o(eta_o f). PASS.
By Check 7, eta_o f is in E2 with ||eta_o f||_(E2) <= C||f||_(E2). Proof 203 (V207) gives a bounded inverse of the normalized origin operator, either the frozen operator of proof 200 or the localized variable operator of proof 202, on its maximal domain in E2, for every alpha < 1 at p = 2 and for small fixed delta. So R_o(eta_o f) is in E2 with norm at most ||R_o|| C||f||_(E2). Multiplying by chi_o keeps it in E2 (Check 7), and compact support gives the L^2(w_gamma) bound from the sup norm. Hence ||K_o f||_Y <= C||R_o||_(E2->E2)||f||_(E2) <= C||R_o|| ||f||_Y. The strain column is inside the normalized operator inverted by R_o. It is well defined on E2 by Check 6, so it raises no domain question. The proof correctly does not assume that the uncut R_o preserves L^2(w_gamma). The output of R_o is used only after chi_o.

10. Boundedness of K_s and the parity of the paired source construction. PASS.
By Check 8(a), the translated forcing is in X_alpha with norm <= C||f||_(E2). Proof 210 (V215) gives L_delta^(-1) bounded X_alpha -> X_alpha with no support condition. This is legitimate for every alpha in (0,1), because alpha < min(1,1/mu) = 1 at the certified source (mu just below 1) and a mu > 1 is certified in proof 209/V214. Then u_+ = chi_+ (R_+ f~)(. - P_+) is globally C^alpha with ||u_+||_(C^alpha) <= C||chi_+||_(C^1)||R_+ f~||_(C^alpha_b), and supp u_+ lies in the positive-source disk, which is separated from x = 0 and from its reflection. Odd-y parity holds. eta_+ is even in y and f is odd, so the forcing is odd in y. In source coordinates the operator (1) of proof 210 commutes with S h(s,y) = -h(s,-y). The reasons: V_delta is reflection-equivariant (proof 209 line 13 and its proof: V1 = ell x + U1[rho0] is even in y and V2 = ell y + U2[rho0] is odd in y, so the homological solutions and the backward-flow correction inherit the equivariance, and the cutoff is radial); M has a symbol even in eta, so it preserves odd-y; U1 = xi eta/|zeta|^2 maps odd-y to even-y, and multiplication by rho0_x(P+X), which is odd in y, restores odd-y; U2 = -M is multiplied by rho0_y(P+X) - g, which is even in y. Proof 210 line 161 records the same fact. L_delta is bijective on D_delta and S preserves D_delta, so S L_delta^(-1) = L_delta^(-1) S and the output is odd in y. chi_+ is even in y, so u_+ is odd in y. Then K_s f = u_+ + u_+(-x,y) is in E2 by Check 8(b), and ||K_s f||_Y <= C||R_+|| ||f||_(E2). No cancellation between the two patches is used. The constant vector by which the L^2 Fourier velocity of u_+ alone differs from the canonical (subtracted at 0) velocity vanishes for the paired, parity-class function K_s f, because U1 is odd in x and U2 is odd in y. The proof's sentence at line 107 is correct in this precise sense, and it is properly left among the unestimated gluing terms.

11. Source-supported strain and its kernel dual norm. PASS.
For supp eta in K with dist(K,0) > 0, the functional f -> (1/pi) integral sin(3theta) r^(-3) eta f dX equals the L^2(w_gamma) pairing of f with kappa = (1/pi) sin(3theta) r^(-3) eta w_gamma^(-1). Its norm on L^2(w_gamma) is exactly ||kappa||_(L^2(w)) = (1/pi)(integral_K sin^2(3theta) r^(-6) eta^2 w_gamma^(-1) dX)^(1/2), which is the displayed C_(eta,gamma). The proof claims only the upper bound, and the bound is finite because r^(-6) and w_gamma^(-1) are bounded on K. The kernel is odd in y and eta is even in y, so restricting f to the odd-y class does not lower this norm. The kernel is even in x (sin 3(pi-theta) = sin 3theta), so for even-x f the paired cutoff eta + eta(-x,y) gives exactly 2c[eta f]. This is the parity-class strain stated at line 117. Since w_gamma <= 1 for gamma >= 0, the bound also gives |c[eta f]| <= C||f||_2 <= C||f||_(X_alpha). This is the rigorous content of statement 5.

The statement block (line 33) and the last section (line 119) explicitly exclude global inverses, a Fredholm parametrix identity, any estimate of I-LK or I-KL, a complement inverse, a closed cubic normalization and any nonlinear theorem. ## Remarks

1. Which origin operator. Statement 3 says "its normalized inverse on E2" from proof 203. Proof 203 proves invertibility on E2 for two operators: the normalized frozen operator of proof 200 and the localized variable-origin operator of proof 202. V219 and V226 later add the actual-variable factorization. Boundedness of K_o holds for any of them, but the proof should say which R_o is meant. In a later parametrix, the meaningful choice is the variable operator, and chi_o and eta_o should then be supported where the extension equals the actual operator (B_(delta/2)). The same applies to chi_+ and eta_+ relative to the region where proof 210's operator equals the actual one.

2. "Once extended with the required parities" (line 95). Evenness in x can be produced by reflection. Oddness in y cannot be produced by extension for a support that straddles y = 0, as the source disk does. It must be a property of the function. In K_s this property is supplied correctly by the equivariance and uniqueness argument (Check 10). The sentence would be cleaner as: "if g is C^alpha, odd in y, and supported in K with K contained in {x >= a}, then g + g(-x,y) is in E2 with norm <= C_(K,alpha)||g||_(C^alpha)". If one wanted to avoid the equivariance input altogether, replacing u_+ by its odd-y part would give the same bound, but it would no longer be the literal source construction.

3. The weighted factor of the input norm is inert in statements 1, 3 and 4. Checks 6, 9 and 10 give |c[f]| <= (4/pi)||f||_(E2), ||K_o f||_Y <= C||f||_(E2) and ||K_s f||_Y <= C||f||_(E2). So K_o and K_s are in fact bounded E2 -> Y. The L^2(w_gamma) factor matters in this proof only for statement 2 (F0 in Y), as a target property, and for statement 5. Its role for the global coupling belongs to V224, not to V222. Saying this would make clear that the gamma > 4k restriction is forced only by F0.

4. The L^2 part is not sufficient for c (Check 6). The proof 208 packets show that c is unbounded on L^inf intersected with C^alpha intersected with L^2(w_gamma). The weighted y seminorm of E2 is what makes c bounded. This supports the proof's reading that the X_alpha unboundedness is an origin effect, and it could be cited as the precise reason.

5. Statement 5 is partly interpretive. The rigorous content is: for every cutoff eta_0 equal to 1 near 0, f -> c[(1-eta_0)f] is bounded on L^inf (the integral of r^(-3) over r > r_0 is finite), hence on X_alpha, and also on L^2(w_gamma) for compactly supported eta. So the unboundedness of c on X_alpha lies entirely in f -> c[eta_0 f], for every such eta_0. The phrase "not an obstruction caused by translation-invariant regularity near P_+" is a fair gloss of this. It should not be read as asserting a normalized source inverse, and the proof does not assert one.

6. Sharper strain constant. The proof's own computation gives |c[h]| <= (4/pi)(||h||_inf + [h]_(y,2)/(1+alpha)). Keeping the angular factor cos^2(theta)|sin(theta)|^alpha would lower the inner constant further. No sharpness of 4/pi is claimed, and none is needed.

7. Strip versus box (line 97). The E2-to-C^alpha comparison holds on the whole strip |x| <= R, uniformly in y. "Bounded box" is not wrong, but it undersells the estimate, which is used only after a compact cutoff anyway.

8. Raw column (line 119). X.grad rho0 is unbounded, so it is outside E2 and therefore outside Y_(alpha,gamma) for every gamma, not just gamma = 1. The stated claim is true but weaker than what holds.

9. Notation. Proof 117 uses R_+ = exp(t_+) for a radius, while proof 213 uses R_+ for the source inverse. The proof never imports proof 117's R_+ explicitly, since it absorbs it into "a fixed nonzero rescaling" S_0, so no error results. A footnote would avoid confusion.

10. VERIFICATION_RECORD wording. The V222 entry has run-together tokens ("gamma1", "boundedY->Y", "weightedL2", "unweightedL2"). The phrase "the origin and source inverses can be used on a single weighted target" should be read as "the cutoff maps are bounded on a single target", which is what the Result and Verdict lines say. No reader of the full entry would infer a parametrix, but the Claim line alone is slightly stronger in tone than the content.
