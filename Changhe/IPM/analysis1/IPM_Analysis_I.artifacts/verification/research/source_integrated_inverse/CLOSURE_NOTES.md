# Final scope and mechanical closure

Both actual Claude Opus5.5 reviews accept the mathematical argument. The
closure review raises three points, resolved here without changing the
frozen producer or its already audited output.

1. In ADDENDUM, the phrase "same physical operator" means the same
auxiliary operator A_s of PROOF. It does not mean the physical IPM
linearization. This clarification supersedes that ambiguous phrase.
The operator is unchanged as ell varies; the norms vary. The exact norm
comparison is ||u||Hs <= N_(1/ell)(u) <= ell^(-s)||u||Hs. Applied to the
input and output of the inverse it gives ||A_s^-1||Hs <= ell^(-s)B_N.
The closure review's weaker vector inequality alone would not establish
this operator norm conversion; the displayed two-sided comparison does.

2. The final closure guard explicitly identifies M_V=743/2500,
M_rho=5059/10000 and delta=33/2000 with topic86's exact scalar inputs,
checks delta also against topics89 and95, and compares all A,mu,g
intervals against topic89's accepted whole-bracket public enclosures.
It checks the five high-derivative ceilings and the order interval, all
current accepted dependency files, and every requested-scale ceiling.
Thus numeric linkage is asserted, not inferred from a filename.

3. The producer's iv tuple decoder lacks an explicit non-finite guard.
The first output audit already checks strictly positive ordered fresh
intervals inside every exported box, which rejects an infinite endpoint
that decodes to zero on these positive scalars. Nevertheless this is an
unnecessary implementation weakness. The closure guard imports the
fresh audit without executing its main, replaces its tuple decoder by
one rejecting negative bit counts before conversion, and recomputes all
4880 scalar containments with Arb1536 and iv250. It fault-tests both
infinities and NaN. It also checks that every exported interval has
strictly positive rational finite endpoints in the right order. No
non-finite value is accepted, and no original output or review bundle
is overwritten. A future producer should use the strict decoder.

The support is the closed ball of radius23delta/8; it is strictly inside
the open ball B_(3delta), and the cutoff is C4. For this cutoff the
coefficient fields are C_c^4. With a smooth cutoff, the original trial
fields could give C_c^6 and C_c^5; that is a different cutoff choice.

REQUESTED_SCALES provides strict outward ceilings at all scales asked
for by the lead, with exact-rational output comparisons. It does not
replace the distinction between a finite list and an optimization over
all scales. The higher-precision audit, complete actual-model review
bundle checks, all accepted input pins and the final verdict are needed
for acceptance. This is not a decisive endpoint.
