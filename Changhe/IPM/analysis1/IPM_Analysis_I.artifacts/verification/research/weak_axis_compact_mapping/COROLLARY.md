# Exact threshold for setwise mapping of the compact annular test class

This follows from the present proof and the separately accepted result192. Fix the canonical exactly joined background and s=153/50. Let T_ann,0 be the real smooth even-x/odd-y densities supported in1<r<2, separated from both axes and satisfying Sigma=0. Then, for every nonnegative b,

 L(T_ann,0) is a subset of Y_(b,153/50) if and only if b<5/2.

For b<5/2, PROOF.md applies to every member. For b>=5/2, axis_weighted_nonlocal_mapping/PROOF.md constructs a single member whose full image has a lower bound c x² on a rectangle adjacent to x=0 and y>0. Its squared zeroth-order weighted integral dominates c² integral_0^epsilon x^(4-2b)dx, which diverges. The same member works for every b>=5/2 and has J=Sigma=0. No additional computational enclosure enters this implication.

This is an equivalence of setwise inclusion for the specified smooth test class. It is not an assertion that L has a continuous extension from its Y norm or the frozen graph norm, and it is not an inverse or a Fredholm claim. Result199 gives unboundedness on the frozen graph domain even for weak weights, using a different compact test sequence. The present equivalence does not concern negative b or membership of the actual residual.
