The whole modal_setup.py source is supplied in the final follow-up. It prepends research/canonical_inverse/code to sys.path and imports exact_poly directly from exact_audit. This is the function reviewed previously, not a different implementation. That function constructs the exact monomial variable t minus the span midpoint. The canonical archive header pins the generating source and Cox source, and the existing knot audit ties them to the exact trial.

The finite source expansion follows from x^2 y = r^3 cos^2(theta) sin(theta) = r^3 [sin(theta)+sin(3 theta)]/4. Multiplication by each cos(2m theta) yields the four frequencies 1+2m, 1-2m, 3+2m, 3-2m with coefficients sign(f)/8 at positive frequency |f|. These are exactly the integer indices j=(|f|-1)/2 and weights in modal_setup. Its sd is formed by exact rational multiplication of those weights with the already normalized S binary64 coefficients from modal_v2.json. The r^3 prefactor is absent from sd and is restored only in the density formula. The normalization repair in setup changes only the outer A and exponential correction coefficients; none of the selected middle S polynomials is changed.

A fresh unit arithmetic audit found that this python-flint version can return nan for abs(arb(-1).union(arb(1)))**2 because the absolute ball has a slightly negative outward lower endpoint.
