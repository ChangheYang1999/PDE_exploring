The C2 hypothesis in the finite statement is intentional. It is sufficient, stronger than necessary, and explicitly assumed. This conditional theorem does not assert that the physical trial satisfies it. There is consequently no need to prove the trial C2 in order to prove the conditional implication. Such a check is needed before a physical application. The new composition does not adopt any inference that a first-derivative jump is harmless because it occurs on a set of measure zero.

This requires matching values and first derivatives for a piecewise smooth representation at all joins.
