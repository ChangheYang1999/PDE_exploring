## 6. The far field and the weight

### 6.1 Lemma TAIL (PROVED, elementary)

Lemma TAIL. Let W = (1 + |X|^2/r0^2)^(sigma/2). Suppose ||F(r, .)||_(L^2(S^1)) >= c r^a for r >= R0, with c > 0 and
a < -1 - sigma. Then
    N(F)^2 >= ||W F||_2^2 >= ||W F||_(L^2(r >= R0))^2 >= c^2 r0^(-2 sigma) R0^(2 sigma + 2a + 2)/(-2 sigma - 2a - 2).
Proof. J^q has symbol <xi>^q >= 1, so N(F) >= ||W F||_2. Also W^2 >= (r/r0)^(2 sigma). Integrate in polar
coordinates. QED.
- P-S1, a = -3: N(F) >= sqrt2 c/R0.
- P-S2, a = -3: N(F) >= c R0^(-3/5)/(6/5)^(1/2).
- For the same angular data the P-S1/P-S2 ratio of the two lower bounds is 1.549 R0^(-2/5): 0.0062 at R0 = 1e6.
- The bound uses W^2 >= (r/r0)^(2 sigma), which is the safe direction of the actual-weight comparison of AT-295.

Remark (CLAIMED, elementary). For r0' >= r0 at the same sigma, 1 + r^2/r0'^2 >= (r0/r0')^2 (1 + r^2/r0^2), so
W_(r0') >= (r0/r0')^sigma W_(r0). A zeroth-order annulus lower at P-S1 (sigma = 1, r0 = 1/2) therefore transfers to
(1, r0') with the factor 1/(2 r0'). For example, the AN089 lower 0.064093 for 007 + b7 gives 0.042728 at (1, 3/4) and
