Corollary BUD-NEC (necessary budget; CLAIMED, Arb). Let U(b0, R, n) = sup_(M > 0) M (Phi(M; b0, R) - n)/R^2, with Phi
the concave majorant of NEC-R (kf = 1). If the direct CE test of T2_H4_v01 section 1.1 passes at rate b0, with some
pair (B, A) admitted by NEC-R, some M and some C0 >= C^opt(b0), at a source with N(F) >= n and R >= Rmin, then
C^opt(b0) <= C0 <= U(b0, Rmin, n).
Proof. The direct inequality at M is N(F) <= b' M - C0 R^2/M, so C0 <= M (b' M - N(F))/R^2. NEC-R gives
b' M <= Phi(M; b0, R). Hence C0 <= M (Phi(M; b0, R) - n)/R^2 <= U(b0, R, n). Phi is nonincreasing in R and 1/R^2
decreases in R, so U(b0, R, n) <= U(b0, Rmin, n) wherever M (Phi - n) >= 0; where it is negative, it is below every
positive value. QED.
Computation (research/h4/bud_nec.py). On [M_a, M_b] each term of Phi is monotone in M, so
Phi <= b0 M_b - sum_i c_i M_a^(p_i) =: PU there, and M (Phi - n) <= max(M_b PU, M_a PU) - n M_a. On [0, M_1] the bound
b0 M_1^2 is used. Beyond b0/lambda_1, Phi < 0. The grid has 20000 equal intervals; the printed values are
3-significant-digit decimals strictly above the Arb upper. Cells marked "excluded" have the B0-THR verdict (no
pass at any C0).

## 4. Scope of the moment lemmas (the first theory agent's note 22 item 3; coord 04:16Z item 2)

Lemmas HI, HI' and MOM and the AT-333 bounds are applied in T2_H4_v01 to three coefficients:
- atil = a_W - sigma c = sigma (ubar.X - c r0^2)/(r0^2 + |X|^2) (scalar). The constant sigma c is the angular limit of
  a_W at infinity. It is subtracted exactly; the linear drift is matched in Proposition DR. atil tends to 0 at
  infinity if and only if ubar.X/|X|^2 tends to 0. The part atil_c tends to 0 like |X|^(-2) and has M2 = 16 c (Remark
  WM).
- S = Sym D ubar (traceless symmetric matrix), through C_aw and the AT-333 matrix bound. Its limit at infinity is 0
  if D ubar tends to 0.
- ubar (vector), through u_3 and u_(3,q) in C_tr and T_IS.
For the registered backgrounds, QWG_v02 Table 4.1 gives a decay of s like r^(-gamma) out to r = 1e5 (FLOAT,
unchanged 007). That is consistent with limit 0 for atil and S, but it is not certified. A coefficient with a
nonconstant angular limit at infinity has a Fourier transform singular like |zeta|^(-2) at 0. It is outside the
AT-333 hypotheses (the first theory agent's note 22) and would have to be split off exactly, as sigma c is for a_W. Certifying the
limits, the moments and the AT-333 hypotheses (Fourier L^1, second moment) for the actual coefficients is part of N2,
which stays OPEN. The first theory agent's note 22 refinement R1 (unit-arc bound for (m, n)) can replace the symbol differences in the
pure high part. R2 gives M2(a) >= ||Delta a1||_inf and an alternative Sobolev upper for M2(S). Both are CLAIMED by
the first theory agent and are not used here.
