## 2. Theorem CE

Lemma P (weight facts; elementary, proofs in section 3).
- (P1) |ell| <= sigma/2. |ell(x) - ell(y)| <= min(sigma |x - y|, sigma). div ell = 2 sigma/(1 + r^2)^2, which lies in
  (0, 2 sigma].
- (P2) 0 < w <= 2 sigma and |grad w| <= L_w. Hence |w(x) - w(y)| <= min(L_w |x - y|, 2 sigma).
- (P3) |v| <= 2 sigma.
- (P4) For all x, y, |W(y)/W(x) - 1| <= Xi(|x - y|) - 1. Xi is increasing, Xi(t) <= (1 + t)^sigma, and
  Xi(t) - 1 <= (sigma/2) t Xi(t).

Lemma K (singular integral form; standard). Let 0 < alpha < 1. For every Schwartz function g on R^2,
    D^alpha g(x) = c_alpha int (g(x) - g(y)) |x - y|^(-2-alpha) dy,
and the integral converges absolutely, because |g(x) - g(y)| <= ||grad g||_inf |x - y| and alpha < 1.
This is the singular integral definition of (-Delta)^s with s = alpha/2 and n = 2. Its constant is
4^s Gamma(n/2 + s)/(pi^(n/2) |Gamma(-s)|), which equals c_alpha here. See M. Kwasnicki, Ten equivalent definitions of
the fractional Laplace operator, Fract. Calc. Appl. Anal. 20 (2017), and also Di Nezza, Palatucci and Valdinoci,
Hitchhiker's guide to the fractional Sobolev spaces, Prop. 3.3. For 2s < 1 the principal value is not needed.
FLOAT check of the constant on exp(-|x|^2/2) at x = 0 (scratch/x4/t_misc.py, output t_misc.out): the Fourier value
2^(alpha/2) Gamma(1 + alpha/2) and the singular integral agree to a relative 4e-15.
Consequently, if f is smooth with bounded derivatives of all orders and g is a Schwartz function (so that f g is one
too), then
    [D^alpha, f] g(x) = c_alpha int (f(x) - f(y)) g(y) |x - y|^(-2-alpha) dy.
This applies to f in {a, ell_i, w}.

Lemma Y (Young). If a kernel satisfies |Kern(x, y)| <= kappa(|x - y|) with kappa(|.|) in L^1(R^2), then
||int Kern(., y) g(y) dy||_2 <= ||kappa(|.|)||_(L^1(R^2)) ||g||_2. In particular, if |f(x) - f(y)| <= min(L |x - y|, O)
for all x, y, then ||[D^alpha, f] g||_2 <= kappa_alpha L^alpha O^(1-alpha) ||g||_2.
Proof: c_alpha int min(L|z|, O) |z|^(-2-alpha) dz = 2 pi c_alpha L^alpha O^(1-alpha) [1/(1 - alpha) + 1/alpha]. Split
at |z| = O/L.

Theorem CE (CLAIMED). Let k be in L^2(R^2), real or complex, with N(k) < infinity. Put R_k = ||k||_2 and
K = ||D^q k||_2. Then K < infinity, and for all rho1 > 0 and rho2 > 0,
    (CE0) K <= ||a D^q(W k)||_2 + sigma ||D^(q-1) k||_2 + 2 sigma ||D^alpha k||_2 + c_w ||k||_2
                + 2 c_alpha [A_n(rho1) ||D k||_2 + A_f(rho1) ||k||_2]
                + c_alpha [I_n(rho2) (||D^2 k||_2 + sigma ||D k||_2 + 2 sigma ||k||_2) + I_f(rho2) ||k||_2],
and therefore
    (CE)  K <= N(k) + E(R_k, K; rho1, rho2),
    E(R, K; rho1, rho2) = sigma X_(q-1) + 2 sigma X_alpha + c_w X_0 + 2 c_alpha [A_n(rho1) X_1 + A_f(rho1) X_0]
                          + c_alpha [I_n(rho2) (X_2 + sigma X_1 + 2 sigma X_0) + I_f(rho2) X_0],
with X_s = R^(1-s/q) K^(s/q). E is nondecreasing in R and in K.

Remarks.
- 2.1. The theorem uses neither the S1 symmetry nor ell_R3, and it uses no property of the background.
- 2.2. Other weights. The proof uses only (P1) to (P4). It gives the same statement for every sigma in (0, 2 + alpha)
  at r0 = 1, after replacing the constants by the corresponding bounds: |v| <= max(2 sigma, sigma^2/4) and
  L_w(sigma) = 2 sigma (4 - sigma) 125/(216 sqrt5) + sigma^2/4 for sigma <= 4. For r0 != 1, dilation X -> X/r0 turns
  (CE0) into the same inequality in which every term c ||D^s k||_2 is multiplied by r0^(s-q), with rho measured in units
  of r0. Only P-S2 is evaluated here.
- 2.3. The form a D^q(W k) is kept in (CE0) because 0 < a <= 1 can be used further when k is located where W is large.
  It is not used below.

## 3. Proofs

Proof of Lemma P.
- (P1) D ell = sigma [(1 + r^2) I - 2 X X^T]/(1 + r^2)^2. Its eigenvalues are sigma/(1 + r^2) and
  sigma (1 - r^2)/(1 + r^2)^2, both of modulus at most sigma, so Lip(ell) = sigma. Next, |ell| = sigma r/(1 + r^2)
  <= sigma/2, so |ell(x) - ell(y)| <= sigma. Finally,
  div ell = sigma [2/(1 + r^2) - 2 r^2/(1 + r^2)^2] = 2 sigma/(1 + r^2)^2.
- (P2) The formula for a radial power, Delta (1 + r^2)^b = 4b (1 + r^2)^(b-2) (1 + b r^2), gives w with b = sigma/2 and
  v with b = -sigma/2. Clearly 0 < w <= w(0) = 2 sigma, since (2 + sigma r^2) <= 2 (1 + r^2)^2. Differentiating,
  w'(r) = -2 sigma r [(4 - sigma) + sigma r^2]/(1 + r^2)^3. We have sup r/(1 + r^2)^3 = (1/sqrt5)(125/216), attained at
  r^2 = 1/5, and sup r^3/(1 + r^2)^3 = 1/8, attained at r = 1. Hence |grad w| = |w'| <= 8 sigma 125/(216 sqrt5)
  + 2 sigma^2/8 = L_w.
- (P3) |v| <= max(2 sigma, sigma^2 r^2)/(1 + r^2)^2 <= max(2 sigma, sigma^2/4) = 2 sigma at sigma = 7/5.
- (P4) Let s = |x| and t = |x - y|. Then (1 + |y|^2)/(1 + |x|^2) <= (1 + (s + t)^2)/(1 + s^2). On s >= 0 the right side
  is maximal where s (s + t) = 1, with value 1/s^2 = (t/2 + (1 + t^2/4)^(1/2))^2. Hence W(y)/W(x) <= Xi(t).
  Exchanging x and y gives W(y)/W(x) >= 1/Xi(t). Since Xi - 1 >= 1 - 1/Xi, this yields
  |W(y)/W(x) - 1| <= Xi(t) - 1. Next, t/2 + (1 + t^2/4)^(1/2) <= 1 + t gives Xi(t) <= (1 + t)^sigma. Finally,
  Xi'(t) = sigma Xi(t)/(2 (1 + t^2/4)^(1/2)) <= (sigma/2) Xi(t), and Xi is increasing, so
  Xi(t) - 1 = int_0^t Xi' <= (sigma/2) t Xi(t).

Proof of Theorem CE.

Step 0 (reduction to Schwartz k; K finite). Put g = W k, which is in H^q. Choose Schwartz functions g_n -> g in H^q
and put k_n = a g_n. Each k_n is a Schwartz function, since a is smooth and all its derivatives are bounded. Then:
- N(k_n - k) = ||g_n - g||_(H^q) -> 0;
- ||k_n - k||_2 <= ||g_n - g||_2 -> 0;
- ||D^q (k_n - k)||_2 <= ||J^q (a (g_n - g))||_2 <= T ||g_n - g||_(H^q) -> 0. Here T is the H^q multiplier bound for
  W^(-1) (AT-187).
The same multiplier bound gives K <= T N(k) < infinity. The fractional norms ||D^s k_n||_2 with 0 <= s <= q converge by
interpolation, and ||a D^q (W k_n)||_2 converges because ||a||_inf <= 1. So both sides of (CE0) pass to the limit,
and it suffices to prove (CE0) for Schwartz k. From here on k is a Schwartz function. Then W k, a(-Delta)(W k),
ell.grad k and w k are Schwartz functions too, because W has derivatives of polynomial growth and ell, w and a have
bounded derivatives of all orders.

Step 1 (identity). Delta (W k) = W Delta k + 2 grad W.grad k + (Delta W) k. Dividing by W,
    -Delta k = a (-Delta)(W k) + 2 ell.grad k + w k.
Since D^q = D^alpha (-Delta),
    D^q k = D^alpha (a Phi) + D^alpha Psi,    Phi = -Delta (W k),    Psi = 2 ell.grad k + w k,
    D^alpha (a Phi) = a D^q (W k) + Gamma,    Gamma = [D^alpha, a] Phi.
Hence K <= ||a D^q(W k)||_2 + ||D^alpha (2 ell.grad k)||_2 + ||D^alpha (w k)||_2 + ||Gamma||_2. Moreover,
||a D^q(W k)||_2 <= ||D^q (W k)||_2 <= N(k), because 0 < a <= 1 and |xi|^q <= <xi>^q.

Step 2 (transport term). Write
    D^alpha (2 ell.grad k) = 2 sum_i ell_i D^alpha d_i k + 2 sum_i [D^alpha, ell_i] d_i k.
- First sum. Pointwise, |sum_i ell_i D^alpha d_i k| <= |ell| |D^alpha grad k|, and
  || |D^alpha grad k| ||_2 = ||D^(1+alpha) k||_2. Since 1 + alpha = q - 1, its L^2 norm is at most
  (sigma/2) ||D^(q-1) k||_2.
- Second sum, by Lemma K. It equals c_alpha int (ell(x) - ell(y)).grad k(y) |x - y|^(-2-alpha) dy. Split
  |z|^(-2-alpha) = (1 - eta_rho1(|z|)) |z|^(-2-alpha) + phi_rho1(|z|).
  - Near part. By (P1) its kernel is at most sigma |z| (1 - eta_rho1) |z|^(-2-alpha) |grad k(y)|. Lemma Y bounds it
    by c_alpha A_n(rho1) ||D k||_2, because || |grad k| ||_2 = ||D k||_2 and
    int_(R^2) (1 - eta) |z|^(-1-alpha) dz = 2 pi int (1 - eta) r^(-alpha) dr.
  - Far part. phi_rho1 is C^1, vanishes for |z| <= rho1 and is O(|z|^(-2-alpha)). Integrate by parts in y:
        int (ell(x) - ell(y)).grad k(y) phi(|x - y|) dy
          = int k(y) [div ell(y) phi(|x - y|) - (ell(x) - ell(y)).grad_y phi(|x - y|)] dy.
    There are no boundary terms, since the vector field (ell(x) - ell(y)) phi is bounded and k is a Schwartz function.
    By (P1) the new kernel is at most 2 sigma phi + min(sigma |z|, sigma) |phi'|. So this part is at most
    c_alpha A_f(rho1) ||k||_2.
Altogether, ||D^alpha (2 ell.grad k)||_2 <= sigma ||D^(q-1) k||_2 + 2 c_alpha [A_n(rho1) ||D k||_2 + A_f(rho1) ||k||_2].

Step 3 (zero-order term). D^alpha (w k) = w D^alpha k + [D^alpha, w] k. By (P2), ||w D^alpha k||_2 <= 2 sigma
||D^alpha k||_2. By Lemma Y with L = L_w and O = 2 sigma, ||[D^alpha, w] k||_2 <= c_w ||k||_2.

Step 4 (weight commutator). By Lemma K, Gamma(x) = c_alpha int (a(x) - a(y)) Phi(y) |x - y|^(-2-alpha) dy. Split the
kernel at rho2 as in Step 2.
- Near part. Write Phi = W Theta with Theta = -Delta k - 2 ell.grad k - w k. Then
  (a(x) - a(y)) Phi(y) = omega(x, y) Theta(y), with omega(x, y) = W(y)/W(x) - 1, and |omega| <= Xi(|x - y|) - 1 by
  (P4). Lemma Y bounds the near part by c_alpha I_n(rho2) ||Theta||_2. By (P1) and (P2),
  ||Theta||_2 <= ||D^2 k||_2 + sigma ||D k||_2 + 2 sigma ||k||_2.
- Far part. Integrate by parts twice. phi_rho2 is C^(1,1), so Green's formula applies with the almost everywhere
  Laplacian. The function y -> (a(x) - a(y)) phi(|x - y|) and its gradient are bounded, by |a| <= 1 and
  |grad a| = a |ell| <= sigma/2. W k is a Schwartz function. So
        int (a(x) - a(y)) phi(|x - y|) (-Delta)(W k)(y) dy = int (W k)(y) (-Delta_y)[(a(x) - a(y)) phi(|x - y|)] dy,
        -Delta_y[(a(x) - a(y)) phi] = (Delta a)(y) phi + 2 grad a(y).grad_y phi - (a(x) - a(y)) (Delta phi)(|x - y|).
  Use W Delta a = v, W grad a = -ell and W(y)(a(x) - a(y)) = omega(x, y). The far part is then
        c_alpha int k(y) [v(y) phi - 2 ell(y).grad_y phi(|x - y|) - omega(x, y) (Delta phi)(|x - y|)] dy.
  By (P1), (P3) and (P4) its kernel is at most 2 sigma phi + sigma |phi'| + (Xi - 1) |Delta phi|. Lemma Y bounds it by
  c_alpha I_f(rho2) ||k||_2.

Step 5 (sum and interpolation). Steps 1 to 4 give (CE0). By Holder's inequality in Fourier variables,
||D^s k||_2 <= ||k||_2^(1-s/q) ||D^q k||_2^(s/q) for 0 <= s <= q, and (CE) follows. E is nondecreasing in R and K
because every term is a nonnegative multiple of R^(1-s/q) K^(s/q) with 0 <= s/q < 1. QED.

## 4. Corollaries

Corollary CE-B (CLAIMED). Let R > 0, M > 0, rho1, rho2 > 0 and Kbar > 0 satisfy Kbar - M - E(R, Kbar; rho1, rho2) > 0.
Then ||D^q k||_2 < Kbar for every k in L^2 with ||k||_2 <= R and N(k) <= M; in particular on K(R, M). Also Kbar > M.

Proof. Put f(K) = K - M - E(R, K; rho1, rho2). Each term of E is a nonnegative multiple of K^(s/q) with 0 <= s/q < 1,
so it is concave in K, and f is convex on [0, infinity). Also f(0) = -M - E(R, 0) < 0. Suppose K >= Kbar, and put
lambda = Kbar/K, which lies in (0, 1]. Convexity gives f(Kbar) <= (1 - lambda) f(0) + lambda f(K), so
lambda f(K) >= f(Kbar) - (1 - lambda) f(0) > 0. Thus f(K) > 0. For K = ||D^q k||_2 with ||k||_2 <= R and N(k) <= M,
Theorem CE and the monotonicity of E in R give K <= M + E(||k||_2, K) <= M + E(R, K), that is f(K) <= 0. Hence
K < Kbar. Finally, if Kbar <= M then f(Kbar) <= -E(R, Kbar) < 0, a contradiction. QED.

Remark 4.1 (order; CLAIMED, constants not evaluated). Take rho1 = 1/4 and rho2 = min(1/4, (R/M)^(1/q)). For
rho <= 1/2 one has I_n(rho) <= C rho^(1-alpha) and I_f(rho) <= C rho^(-1-alpha); the first follows from (P4) with
Xi(2 rho) <= Xi(1), the second from the explicit form of phi on [rho, 2 rho] and beyond. Then every term of
E(R, 2M)/M is O((R/M)^(1/q)) as R/M -> 0, and Kbar <= 2M is admissible for R/M small. Since q = 2 + alpha,
X_2 = R^(alpha/q) K^(2/q). The near term gives
    c_alpha I_n(rho2) X_2 <= C (R/M)^((1-alpha)/q) R^(alpha/q) M^(2/q) = C R^(1/q) M^(1-1/q),
because (1 - alpha)/q + alpha/q = 1/q and (2 - 1 + alpha)/q = (q - 1)/q. The far term gives
    c_alpha I_f(rho2) X_0 <= C (R/M)^(-(1+alpha)/q) R = C R^(1/q) M^(1-1/q),
because 1 - (1 + alpha)/q = 1/q. The leading transport term sigma X_(q-1) = sigma R^(1/q) K^(1-1/q) has the same order.
The other terms (X_alpha, X_1, X_0 with constants bounded for rho2 <= 1/4) carry higher powers of R/M, since
1 - alpha/q, 1 - 1/q and 1 all exceed 1/q. Hence the smallest admissible Kbar satisfies Kbar/M = 1 + O((R/M)^(1/q)).
On the other side, E >= sigma X_(q-1) gives Kbar/M - 1 >= sigma (R/M)^(1/q) for this E; that is a property of the bound only.

## 6. X4 status: c_4', the tame route and "only ||F||_2 small"

- c_4' = 1 + delta0 is the tame coefficient of AT-114 (1). On route Q (Theorem HF-Q, AT-237) the k-dependent transport
  term is bounded by L_B G^2 with no tame term (T_1 = 0, Proposition S0). So c_4' does not enter, and the c_4' part of
  the X4 item is moot on this route. Wherever an estimate on K(R, M) enters only through ||D^q k||_2 <= c_W M and is
  monotone in that quantity, Corollary CE-B lets Kbar(R, M) replace c_W M. This includes the strain and velocity
  interpolations of AT-071 (1), AT-186 and AT-187. Theorem CE bounds the homogeneous norm only. Estimates written with

  ||J^q k||_2 <= 2^(q/2-1) (||k||_2 + ||D^q k||_2) <= 2^(1/20) (R + Kbar), with 2^(1/20) < 1.0353.

  - through Kbar(R, M)/M - 1 = O((R/M)^(1/q)).
