## 0. Summary

1. In the weighted Sobolev framework of the first theory agent (norm N(f) = ||<D>^q (W f)||, 2 < q < 3), the operator A_k = L + U[k].grad
   adds only perturbative terms to the k = 0 energy inequality (Lemma WG of the first theory agent): the transport part is skew
   (div U[k] = 0), and the commutator is tame. This gives a k-uniform estimate (UT-S) whose constants do not depend on k:
       (beta - eps - kappa(k)) N(z) <= N(G) + c_4 N(k) (||grad z||_inf + ||z||_inf) + ((beta - eps - kappa(k)) C_eps)^(1/2) ||z||,

## 2. Lemma GN (explicit Fourier-L^1 interpolation). Status: CLAIMED

Let 2 < q < 3 and f in L^2 cap Hdot^q real. For p in {0, 1} and a bounded angular factor w(phi) >= 0 put
I_w = int_0^(2 pi) w(phi)^2 d phi. Then
    (2 pi)^(-2) int |xi|^p w(phi) |fhat(xi)| d xi <= C(q, p, I_w) ||f||^(t_p) ||f||_(Hdot^q)^(1 - t_p),   t_p = (q - p - 1)/q,
    C(q, p, I_w) = (2 pi)^(-1) (1 + P/Q) A^(Q/(P+Q)) (Q B/P)^(P/(P+Q)),   P = p + 1, Q = q - p - 1,
    A = (I_w/(2p + 2))^(1/2),   B = (I_w/(2q - 2p - 2))^(1/2).
Proof. Split at |xi| = rho. Cauchy-Schwarz on |xi| < rho gives (I_w rho^(2p+2)/(2p+2))^(1/2) ||fhat||_2 = 2 pi A rho^P ||f||.
On |xi| > rho write |xi|^p = |xi|^(p - q) |xi|^q; Cauchy-Schwarz gives 2 pi B rho^(-Q) ||f||_(Hdot^q) (the integral
int_rho^infinity r^(2p - 2q + 1) dr converges since q > p + 1). The minimum over rho > 0 of A a rho^P + B b rho^(-Q) is
(1 + P/Q) (A a)^(Q/(P+Q)) (Q B b/P)^(P/(P+Q)) (elementary calculus). QED.
Consequences (each left side is bounded by the Fourier integral of the stated kind):

## 3. Lemma P (low/high split of the velocity)

Let phi be a smooth radial cutoff, phi = 1 on |xi| <= 1, phi = 0 on |xi| >= 2, 0 <= phi <= 1. Put U_lo := phi(D) U and
U_hi := (1 - phi(D)) U.
(i) (CLAIMED) For every multi-index b, ||d^b U_lo[k]||_inf <= (2 pi)^(-1) ||xi^b phi(xi) m(xi)||_(L^2(d xi)) ||k||_2 <=
    (2 pi)^(-1) (pi 2^(2|b| + 2)/(2|b| + 2))^(1/2) ||k||_2. Proof: Fourier inversion, Cauchy-Schwarz, Plancherel,
    |xi^b| <= |xi|^|b|, |m| = |cos phi|, support in |xi| <= 2. So U_lo[k] is a smooth bounded divergence-free field with
    every derivative bounded linearly in ||k||_2.
(ii) (standard tool, not new) (1 - phi) m_i is a symbol of order 0 that is smooth on R^2 (it vanishes near xi = 0). Its
    kernel is c_i delta + K_i, with K_i a Calderon-Zygmund kernel near the origin and |d^g K_i(z)| <= C_(N,g) |z|^(-N) for
    |z| >= 1 and all N (integration by parts in xi; e.g. Stein, Harmonic Analysis, chapter VI).
(iii) (standard tool, not new) Consequently, for the weights W above and 0 <= s <= 3,
    ||W <D>^s U_hi[k]|| <= C ||W <D>^s k||,   and   ||W <D>^s f|| and ||<D>^s (W f)|| are comparable,
    with constants depending on (s, sigma, r0, phi), for EVERY sigma >= 0. Reason: the near-diagonal part acts locally,
    where W is comparable to a constant on balls of radius r0; the far part decays faster than the weight grows (Peetre);
    W is a symbol of order sigma, so commuting it with <D>^s costs lower-order terms.
By contrast, U itself is bounded on L^2(W^2) only if W^2 is an A_2 weight, that is sigma < 1. The obstruction comes
entirely from the low frequencies, which (i) handles with ||k||_2.

## 4. Lemma KP-W (weighted tame commutator). Status: OPEN as a written proof

Statement. Let 2 < q < 3, sigma >= 0, r0 > 0. There are c_1, c_2, c_3, c_4, depending only on (q, sigma, r0, phi), such
that for real k with W k in H^q, a := U[k], and real h with u := W h in H^q (first for Schwartz h, k):
    | Re < <D>^q [W (a.grad h)], <D>^q u > | <= ( c_1 eps(k) + c_2 ||k||_2 + c_3 ||a||_inf ) ||u||_(H^q)^2
                                                   + c_4 N(k) ( ||grad h||_inf + ||h||_inf ) ||u||_(H^q).
Route (HEURISTIC until written in full).
1. W (a.grad h) = a.grad u - (a.grad log W) u.
2. Since div a = 0, Re < a.grad g, g > = 0 for g = <D>^q u; only [<D>^q, a.grad] u remains. Split a = a_lo + a_hi
   (Lemma P). For a_lo, smooth-coefficient commutator calculus gives ||[<D>^q, a_lo.grad] u|| <= C ||k||_2 ||u||_(H^q)
   (Lemma P(i)). For a_hi, Bony's decomposition: the low-a/high-u piece and the resonant piece are bounded by
   C eps-type sups of D a_hi (note ||D a_hi||_inf <= eps(k) + C ||k||_2) times ||u||_(H^q). The high-a/low-u piece is
   Sum_j S_(j-1)(grad u) Delta_j a_hi. Here the weight is transferred pointwise: |S_(j-1)(grad u)(X)| <= C W(X) A(h)
   (Peetre and the uniformly bounded weighted L^1 moments of the kernels of S_(j-1); grad u = W (grad h + h grad log W)),
   and by almost orthogonality and Lemma P(iii), the sum is bounded in H^q by C A(h) ||W <D>^q U_hi[k]|| <= C A(h) N(k).
3. The product (a.grad log W) u is treated in the same way: ||a.grad log W||_inf <= (sigma/(2 r0)) ||a||_inf gives the
   c_3 term, and the high-a/low-u piece uses |S_(j-1) u| <= C W ||h||_inf.
The standard Kato-Ponce estimate would instead give ||D a||_(H^(q-1)) ||grad u||_inf, and ||grad u||_inf = ||grad(W h)||_inf
is not small when ||h||_2 is small (translate a bump to large |X|); this is the first theory agent's NR-4 objection, and step 2 is the answer
to it. Sharper principal coefficient (HEURISTIC): the principal symbol of the commutator gives
Re < [<D>^q, a.grad] u, g > = q int (Rt g)^T (Sym D a) (Rt g) + remainder, Rt_j = d_j <D>^(-1) (as in the first theory agent (K3)), so one
expects c_1 = q + (small) at the price of a term C ||D a||_(C^delta) ||u||_(H^q)^2 with small delta > 0, which is again
R-small by interpolation. An independent proof or refutation is requested (the external referee tag t2-kpw1, launched 19:17Z).

## 6. Closure: Lemma S2, Theorem D-S and Corollary D1-S

Lemma S2 (two-power sublevel lemma). Status: CLAIMED. Let a >= 0, b_1, b_2 >= 0, theta_1, theta_2 in (0, 1), M > 0, and let
x in [0, infinity) satisfy x <= a + b_1 x^(1-theta_1) + b_2 x^(1-theta_2). If a + b_1 M^(1-theta_1) + b_2 M^(1-theta_2) <= M,
then x <= M.
Proof. Let f(x) = x - a - b_1 x^(1-theta_1) - b_2 x^(1-theta_2), continuous on [0, infinity), f(0) = -a <= 0, f(M) >= 0.
If b_1 = b_2 = 0, f(x) <= 0 gives x <= a <= M. Otherwise f'' > 0 on (0, infinity), so f is strictly convex on
[0, infinity). Suppose f(x) <= 0 and x > M. With t = M/x in (0, 1), strict convexity gives
f(M) < (1 - t) f(0) + t f(x) <= 0, a contradiction. QED.
This contains Lemma S(ii) of v01 (one power, AT-017) and also covers a = 0, the case AT-020 asked to treat separately.
Finiteness of x is essential, as in AT-017.
