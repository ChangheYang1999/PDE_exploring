## 3. Lemma KP-W. Status: CLAIMED (complete proof in theory_agent_2/research/kpw/PROOF.md)

### 3.1 Statement (copied from PROOF.md section 0)

Let 2 < q < 3, sigma >= 0 and r0 > 0. For real k put a := U[k] and ell := grad log W. For real u put h := W^(-1) u, so that
||u||_(H^q) = N(h). For Schwartz k and u, define
    F(k, u) := [<D>^q, a.grad] u - <D>^q[(a.ell) u],    E(k, u) := Re (F(k, u), <D>^q u).
(i) For real Schwartz k and u:
    ||F(k, u)|| <= (c_1 eps(k) + c_2 ||k||_2 + c_3 ||a||_inf) N(h) + c_4 N(k) A(h),
    Re (<D>^q [W (a.grad h)], <D>^q u) = E(k, u),
and hence
    | Re (<D>^q [W (a.grad h)], <D>^q u) | <= (c_1 eps(k) + c_2 ||k||_2 + c_3 ||a||_inf) N(h)^2 + c_4 N(k) A(h) N(h).
(ii) F extends continuously to real k with W k in H^q and real u in H^q, and the bound on |E(k, u)| holds for all such data.
(iii) For such data, the literal pairing need not exist.
Constants (PROOF.md section 0 (iv)):
- c_1 = C_q;
- c_2 = C_(q,phi) (1 + M_ell);
- c_3 = C_q M_ell;
- c_4 = C_q G C_W (1 + L + M_ell);
- M_ell <= C_q sigma sum_(r=1..4) r0^(-r), and L = sigma/(2 r0).
The low-frequency commutator constant is explicit: C_lo = q 3^(q-1)/sqrt(pi), which is 7.33 at q = 5/2. No other constant is
evaluated.

### 3.2 Weight placement (coordinator 19:12Z item 3; the first theory agent NR-4)

The weight is placed on the solution, u = W h. It reaches the coefficient only through N(k) = ||<D>^q (W k)||. U is never
used as an operator on a weighted L^2 space. This avoids NR-4's A_2 obstruction: W U W^(-1) is bounded on L^2 only for
sigma < 1. The proof handles the coefficient in three parts.
(a) The low part a_lo = U[phi(D) k]. Every derivative of a_lo is bounded by C ||k||_2 (Lemma P(i), AT-034). Its commutator
    with <D>^q costs C_lo ||k||_2 N(h) (PROOF.md Lemma C_lo).
(b) The high part b = U[(1 - phi(D)) k]. Its symbol (1 - phi) m is smooth, so the dyadic blocks W Delta_j b are controlled
    by W <D>^q k for every sigma >= 0 (PROOF.md Lemma M and Lemma SQ: B_q(b) <= C_W N(k)).
(c) The high-coefficient/low-solution paraproduct sum_j S_(j-3)(d_i u) Delta_j b_i. In the standard Kato-Ponce estimate
    this term would carry ||grad (W h)||_inf, which ||h||_2 does not control (translation counterexample, NR-4). Here the
    weight moves pointwise from u to the coefficient (Peetre; PROOF.md Lemma T):
        |S_m d_i u(X)| <= G W(X) (||grad h||_inf + L ||h||_inf).
    So the tame term is c_4 N(k) A(h). It contains unweighted sups of h, which (S-int) makes R-small.
Consequences:
- KP-W holds for every sigma >= 0 and r0 > 0, and NR-4's expected restriction sigma < 1 is not needed for the k-terms.
- The sigma window of FW-C2-Hq-v1 is set by the other hypotheses only:
  - Lemma E and Lemma WG: sigma < 1 + gamma_*;
  - BG-q at infinity: sigma >= q - 1 - 1/c + beta/c;
  - N(F) finite: sigma < 4 - 4/c_l (AT-048 for Candidate 007; AT-012).
- UT-S uses KP-W only in form (i). The energy form (ii) is what the inequality means at H^q regularity.
