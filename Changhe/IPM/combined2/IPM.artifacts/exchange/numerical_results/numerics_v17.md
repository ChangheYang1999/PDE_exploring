N49.1 Quantities and exact identities. Setting and normalizations of SCREEN_specification_v01: f^(zeta) = int e^(-i X.zeta) f(X) dX, m_k(f) = (2 pi)^(-2) int |zeta|^k |f^(zeta)| d zeta (Euclidean norm of vectors, operator norm of matrices), S = Sym D ubar, u_3 = m_3(ubar), M_S = 3 m_2(S) + 2 m_4(S), r_3 = m_3(grad rhobar) = m_4(rhobar). The center's fields are chi (the 007 quotient, cos(2m theta) modes) and phi (the h_* atoms, sin(n theta) modes, n odd), with rhobar = -d_y Delta chi - Delta phi and ubar = (-chi_xyy, chi_xxy) + (-phi_xy, phi_xx). With the stream function Psi = chi_xy + phi_x (ubar = (-Psi_y, Psi_x); sine modes, even N) and Phi_c = chi_y + phi (rhobar = -Delta Phi_c; sine modes, odd N), the symbols give |ubar^| = |zeta| |Psi^|, ||S^||_op = |zeta|^2 |Psi^| / 2 (the real symmetric symbol matrix B of S^ = B Psi^ satisfies B^2 = |zeta|^4 I / 4), |S^|_F = |zeta|^2 |Psi^| / sqrt 2 and rhobar^ = |zeta|^2 Phi_c^, hence the EXACT identities between the Fourier moments
  u_3 = m_4(Psi) = 2 m_2(S),   m_4(S) = m_6(Psi) / 2,   r_3 = m_4(rhobar) = m_6(Phi_c).
Hypotheses (made precise by the referee pass, N49.5 (f); the same premises as the first theory agent's note 103 item 2): let f be a tempered field whose order-k Cartesian derivatives are continuous and vanish at infinity, and suppose its Fourier transform, restricted away from zero, has a measurable density a_f with int |zeta|^k ||a_f(zeta)|| d zeta finite; define m_k(f) with this density. Then ||Q(grad) f(X)|| <= m_k(f) for every homogeneous polynomial Q of degree k with |Q(zeta)| <= |zeta|^k (the inverse transform of Q(i zeta) a_f is continuous and vanishes at infinity, its difference from Q(grad) f has Fourier support at zero and is a polynomial, and the decay makes that polynomial zero; the polynomial Psi = x^3 y, with zero density away from the origin and ||Delta S||_op = 6, shows that the decay condition cannot be dropped). For the 013 fields the finite atom representation gives D^alpha Psi = O(r^(1 + gamma - |alpha|)) and D^alpha Phi_c = O(r^(2 + gamma - |alpha|)) with gamma = 1/c (FLOAT decimal approximately 0.5523887690; many h_* atoms have the degree tau = mu = 4/c - 3 exactly, FLOAT decimal approximately -0.7904449, so phi itself decays like r^mu and the density correction -Delta phi like r^(mu - 2)); together with the global smoothness of the finite atom representation these estimates imply that Delta^2 Psi, Delta^3 Psi and Delta^3 Phi_c (leading powers gamma - 3, gamma - 5, gamma - 4) lie in L^1 and H^2, so the moments above are finite; their values are the question. Lemma MOM (the second theory agent T2_H4_v01; eps = 1 in SCREEN_specification_v01): m_k(f) <= (4 pi)^(-1/2) || |D|^k (1 - Delta) f ||_2 (Cauchy-Schwarz against (1 + |zeta|^2)^(-1), with int (1 + |zeta|^2)^(-2) d zeta = pi and Plancherel ||f^||_2 = 2 pi ||f||_2). Applied to the scalar potentials and combined with the identities: u_3 <= (4 pi)^(-1/2) ||Delta^2 (1 - Delta) Psi||_2, m_2(S) <= half of that, m_4(S) <= (4 pi)^(-1/2) ||Delta^3 (1 - Delta) Psi||_2 / 2, r_3 <= (4 pi)^(-1/2) ||Delta^3 (1 - Delta) Phi_c||_2 = (4 pi)^(-1/2) ||Delta^2 (1 - Delta) rhobar||_2 (applying the lemma to S with the Frobenius norm instead gives the weaker factor 1/sqrt 2 for the two strain moments; this agent's 10:36Z note used it and its 10:41Z note corrected it).
