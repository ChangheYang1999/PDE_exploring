Claim: O preserves the selected member's private history. Verdict: CONFIRMED as a conditional source argument. The module advances separate fresh G and L objects on separate copied round-one observations, requires exact ordered action-list equality, selects L at round two exactly when both opponent buildings and roster are empty, and thereafter advances only that same object. Its sequence checks reject skipped rounds or changed seats. The shared 20-wall route argument is sufficient for legality without any assumption about shortest-path tie breaking; 80 remaining gold buys four factories. The proof distinguishes selected-member state from O's extra bookkeeping and unused instance. Its full-game induction correctly requires matching decision-relevant environmental inputs for both the selected policy and opponent. In particular, equal observations do not imply equal deadline branches in frozen fortress planners. Exceptions and retries after partial advancement are outside the supported hypothesis.

Claim: the amended checker measures selected-member action and logical-state agreement on complete histories. Verdict: CONFIRMED by source inspection, conditional on successful execution. It reconstructs the unchanged engine, checks the exact initial records, exactly two records per reached round, ordered round/player fields, no earlier terminal result, and a matching non-null final result. It calls O and a fresh standalone actual selected G or L from round one, compares both actions with the retained submission, validates actions with original apply_action, compares selected state after every call, checks branch permanence, checks unchanged input observations, and replays both players' recorded actions. The resolver stores the factory-returned bound method directly, so reference.decide.__self__ is the intended G or L object.

The new canonicalizer includes G's defender closure and L's PersistentFactoryModel, bound H owner, nested opening/defender and traces. It includes function closure values and defaults, object fields and container contents. Cycles and unsupported types raise. It compares logical value trees; shared module globals, alias identity, dictionary insertion order and clocks are outside this representation. These exclusions must remain attached to the phrase persistent-state agreement. Source equality under the fixed imports and the recorded action checks supply context; the serializer is not a universal Python-state equivalence proof. It is selected-member transfer evidence only when the actual and predeclared branches agree; otherwise it is a predeclared-baseline comparison. Third, equal nonzero O-self outcomes trigger an assertion before H3 REFUTED and final results are written. This prevents an invalid diagonal certificate, but that failure path does not produce the promised final falsification report. These are conditional reporting limitations, not observed game failures.
