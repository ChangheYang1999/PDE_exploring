1. Eligibility and unchanged observations. CONFIRMED. `ImmuneShortcut` accepts no parameter overrides. The fast predicate requires round greater than 5, current splash immunity, and an empty stage-zero wall plan at the same starting gold and layout as the parent. `plan_walls` modifies copied buildings and a local blocked set. The guard does not mutate the observation or policy fields. It does run before the parent's pending update, but those pure computations do not depend on pending or failed state. When the predicate fails, the original `_decide` runs. When it succeeds, the original empty wall plan leaves gold and actions unchanged, and `_with_buildings` is equal to the original observation by value for all subsequent computations. The claim is about values and legitimate state, not object identity or cache contents.

2. Defense early return and splash bound. CONFIRMED. Under the bundled catalog every minion has HP at most 1500 and the splash type deals 10 damage per adjacent path cell. Frozen v7 `adjacency_total` and gamekit `splash_total` use the same routed non-base cells; thus exposure at least 1500 gives adjacency at least 150. For every visible or sampled composition, v7 `plan_defense` computes required adjacency at most 150 and returns an empty list at its existing-adjacency check, before its search and simulation branches. Empty compositions also return an empty list. Budget, partial-plan mode and the gun-cap argument do not invalidate this early return.

The separate `_worst_leak` call also returns zero for these compositions. A copy that reaches the base crosses every preceding path cell, receives splash there independently of other copies, and dies once its HP is exhausted. Base arrival precedes turret fire, which is why the base cell must be excluded. The spawn cell is included. Copies born late through the modulo schedule either receive the full exposure before arrival or never arrive within the 250-tick round. Guns cannot increase survival. This establishes zero even for rosters with more than 250 entries. The argument uses the route actually computed by the unchanged helpers, so it does not assume a different shortest-path tie break.

3. Insurance and sticky state. CONFIRMED. The default positive `big_threat` is 100, so zero worst leak prevents the full-budget fallback and its nested fortress-gun alternative. Rounds greater than 5 exclude default poke insurance through round 3 and mid-tier insurance through round 5, including the joint and reactive branches. The parent nevertheless evaluates the insurance-options expression before testing composition availability or positive gold. Since default `splash_insurance` is false, it calls `_fortress` exactly once. The shortcut preserves that call even at zero gold or with no sampled compositions. It therefore preserves the sticky `fortress` flag, including its transition when projected opposing income first crosses the tier5 threshold.

4. Pending attacks and purchases. CONFIRMED. Both versions increment `failed` only when an immediately previous pending attack achieves less than half its prediction, then clear `pending`. A stale pending entry is cleared without incrementing the counter in both. With no defensive spending and an unchanged immune map, round greater than 5 satisfies default `attack_from=6`. Default `immune_attack=True` and `immune_share=None` select the same explicit `current` mode and integer budget `int(left * attack_share)`, with `attack_share=0.5`. Both call the same `_attack` on the original observation and rules, preserve purchase ordering, subtract the same minion cost, and install the same pending tuple only when purchases are nonempty. Passing `current` bypasses the failed-dependent adaptive mode in both executions. The catch-up branch cannot add another attack: positive gold enters the ordinary attack branch; zero gold fails the catch-up gold guard.

Factories use the same post-attack gold, default per-round cap 40, factory cost, and last allowed round 46. The parent subtracts their cost from its local `left`; the shortcut returns after extending the same action list. That discarded local difference is not a persistent-state or action difference.

5. Caller, requested cells and module entry point. CONFIRMED. The shortcut inherits `__call__` exactly. The foreign-building test therefore installs the same delegate and switch round before `_decide`, or invokes an already installed delegate before eligibility is tested. Native calls update `requested` from the same returned build actions. The shortcut's `make` and player-keyed module wrapper construct fresh default instances, with the same round-1 reset rule as the frozen parent. Equal legitimate state here means equal parameter and layout values, pending tuple, failure counter, fortress flag, requested cells, switch-round value, and corresponding delegate closure state when one exists. It excludes Python function identity, cache state and elapsed time.

6. Foreign-delegate theorem scope. INITIAL ARGUMENT INCOMPLETE; AMENDED SCOPE CONFIRMED. Identical foreign source is insufficient to prove equal outputs for all independently scheduled executions. Frozen v20 `make` has `plan_time=1e6`, passes that finite value to frozen v15 `plan_defense`, and that planner tests `time.time() > deadline` in its gun-search path. The large value is not a mathematical removal of deadline branches. The frozen v26 replanner used here receives no time budget and uses its specified local seed, so its default call does not add another active deadline premise.
