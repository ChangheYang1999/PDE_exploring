# H10 transfer after the failure-count ablation

Declared before these games. H10 has defeated v27 P5TNU with failure
thresholds 2, 3 and 4. Whether always-current attack also loses is OPEN.
The test uses P5TNUF3 with only attack_mode changed to current, plus a
repeated P5TNUF3 control. Test frozen F34, F35, E25RM, E27 and best_v9e on
the same two handoff timings H10 and H12, both seats, 28 conditions.
The conjecture is that early defense closes the attack window even with
always-current attack. Cross-family transfer is exploratory. The F3 repeat
is a reproducibility check, not an independent sample. F34's planning
retains a time cutoff, so all observations are execution-specific.

Every result requires source/data freeze checks, strict outcome accounting,
original-engine replay, and normalized seat-history comparison. H10 and
H12 were already used in development; no reserved validation is consumed.
