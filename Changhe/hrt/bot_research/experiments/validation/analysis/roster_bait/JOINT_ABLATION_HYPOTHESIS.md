# Joint-plan and opening-guard controls

The prior forty games showed identical behavior for mid_relevant=false and
true under every roster-bait condition. In particular, one or two tier1 bought
in round two win without any turret, while three tier1 and one tier2 do not.
These are already observed development results.

Repeat all ten opponent conditions and both assignments with mid_joint=None.
A second arm adds r1_gun=[4,1], leaving every other parameter unchanged. Both
arms use the same private V23 snapshot and all other prior explicit parameters.
Compare the first arm with all twenty prior relevance-true games, and compare
the guard arm both with that baseline and with the first arm. No condition is
selected by outcome. This makes forty new games and sixty descriptive paired
comparisons, which reuse the same forty new and twenty old executions.

Hypotheses: disabling the joint plan removes the small-bait losses; adding the
opening guard does not reintroduce them. Either may be refuted. The first
comparison isolates one configured policy parameter, not a single action or
pure spending effect. The guard changes the round-one gun, poke count and
available factory gold together. No result constitutes held-out evidence.
