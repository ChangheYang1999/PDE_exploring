# Data-analysis interview

`data/games/` contains 1,000 games generated by 30 unknown bots. Their
identities are anonymous labels `bot1` through `bot30`; `target` is the bot
identity. Each game contributes one row per player.

Open `analysis.ipynb` from the repository root:

```bash
jupyter notebook data_analysis/analysis.ipynb
```

The notebook calls `build_feature_df(log_dir)` from `features.py` and stops
after displaying the initial feature table. It has shape `(2000, 6)`, a
MultiIndex named `(game_id, player)`, and these columns in order:

| Column | Meaning |
| --- | --- |
| `n_factories` | Final factory count |
| `n_turrets` | Final attacking turret count, excluding walls |
| `length_path` | Final path length in movement steps |
| `n_minions` | Total successful minion purchases over the entire game, including expired entries |
| `result` | Win: 1; draw: 0; loss: -1 |
| `target` | Anonymous bot identity |

You may perform further analysis and modeling during the interview.
