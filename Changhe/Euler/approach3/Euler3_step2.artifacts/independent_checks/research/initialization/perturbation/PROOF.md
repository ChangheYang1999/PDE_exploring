# Field-relative coefficient perturbations at fixed physical parameters

## Statement and notation

Fix a physical parameter pair p = (c_l, omega) in (2/5, 1/2) x (0, infinity). Let X be a finite-dimensional real coefficient space. Let H = (R^3)^N for a positive integer N, with norm

    ||v||_W^2 = sum_{i=1}^N w_i |v_i|^2,

where each weight w_i is strictly positive. Let V_p: X -> H be the linear map that evaluates the represented velocity at N specified spatial points with the physical parameters held at p. Let C,d belong to X, and assume ||V_p C||_W > 0 and ||V_p d||_W > 0. For a prescribed epsilon > 0, define

    t = epsilon ||V_p C||_W / ||V_p d||_W,
    C_new = C + t d.

Then

    ||V_p C_new - V_p C||_W / ||V_p C||_W = epsilon.

Suppose also that T_p: X -> Y is linear, where Y is a finite-dimensional real space of leading-tail coefficients, and that T_p d = 0. Then T_p C_new = T_p C. Consequently every quantity that depends only on this leading-tail coefficient vector is unchanged. This includes its norm and any deterministic phase-pivot rule defined exclusively from it, provided the rule uses the same tie convention.

If S is a linear subspace of allowed coefficient directions and d belongs to S, then C_new - C belongs to S. No assertion that projection onto ker T_p preserves S is made without an additional invariance hypothesis.

## Proof

Linearity at the fixed pair p gives

    V_p C_new - V_p C = V_p(C + t d) - V_p C = t V_p d.

Both norms in the definition of t are positive, and epsilon is positive, so t is positive. Absolute homogeneity of the norm therefore yields

    ||t V_p d||_W / ||V_p C||_W
      = t ||V_p d||_W / ||V_p C||_W = epsilon.

Similarly, linearity of T_p and T_p d = 0 imply

    T_p C_new = T_p C + t T_p d = T_p C.

A function of an unchanged argument has the same value when evaluated by the same rule. Finally S is a vector subspace, so it is closed under scalar multiplication and t d belongs to S. These statements prove all the conclusions.

## Reduced coordinates and parameter slots

Suppose the allowed physical coefficients are generated by a linear map E_p: R^k -> X. A reduced direction a represents d = E_p a. If an implementation instead uses an affine coordinate map E_p(a) = L_p a + b_p, the correct coefficient direction is L_p a = E_p(a) - E_p(0). The preceding proof then applies to this d.

The full software state (C,p) is not a vector of coefficients at one fixed parameter pair. In particular, evaluating the numerical state (d,0,0) asks for V_(0,0)d; it does not ask for the coefficient derivative V_p d. The pair (0,0) is outside the stated parameter domain. The formulas alpha = (1-c_l)/c_l and kappa = omega/c_l are undefined there. A valid implementation evaluates (d,p), or computes V_p(C+d)-V_p C, while keeping the actual increment's parameter entries zero before adding it to the original state. Zero increment in a parameter is different from zero value of that parameter during evaluation.

## Restricting the direction before projection

To preserve an allowed subspace S, choose a linear inclusion Q: R^q -> X whose range is S and find a reduced direction a in ker(T_p Q). Then d = Q a lies both in S and in ker T_p. This proves simultaneous preservation of the selected modes and the leading tail.

Projection onto ker T_p in the whole space need not preserve S. For example, take X = R^2 with its Euclidean norm, S = span((1,0)), and T(x,y) = x+y. The orthogonal projection of (1,0) onto ker T = span((1,-1)) is (1/2,-1/2), which is not in S. A model-specific block structure might make the projection preserve a mode restriction, but that property must be established or checked rather than inferred from the initial mask.

## Scope and dependencies

These are exact finite-dimensional statements, using only linearity and norm homogeneity. They do not establish the linearity of a particular implementation; that requires its representation formula or an independent test. They also do not establish that a truncated numerical singular-value decomposition gives an exact kernel vector. A computed projection has a measured tail residual, and an exact conclusion requires a justified error bound.

The choice w_i = 1 gives the unweighted training-grid Frobenius norm. A positive quadrature weighting gives a different perturbation normalization. Agreement with either finite-grid size does not prove a continuum norm estimate, a derivative bound, a small Euler residual, or convergence to an exact solution. The whole represented field is never rescaled in this construction.
