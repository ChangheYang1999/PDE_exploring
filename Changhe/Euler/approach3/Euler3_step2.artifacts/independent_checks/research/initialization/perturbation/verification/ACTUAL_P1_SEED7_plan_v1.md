# Independent check of the P1 seed-seven perturbation

This check is registered after the producer sidecar was read and before the independent field computation. It reuses the tolerances and independent velocity route of ACTUAL_F3_plan_v1.md. It is a post-generation verification, not prospective evidence about which perturbation would optimize best.

Bind the exact P1 s4 source and seed-seven output, their sidecar, the v1.1 generator, the producer layout, and the independent field sources. Reconstruct the Gaussian direction with integer seed 7, zero every m=0 coefficient and every inactive E l=1 coefficient, and check the claimed scaling in coefficient space at the unchanged tolerance of two binary64 epsilons relative to each coefficient. Compare the excluded coefficients as uint64 bytes, including signed zeros. Verify the next two Gaussian signs and the independent logit/exponential parameter map. Parameter-coordinate comparisons use relative 1e-12 and absolute 1e-14 tolerances, declared before this run.

Independently reconstruct the velocity at the original parameters before the parameter move, then at the actual perturbed parameters. On the producer training geometry, compare coefficient-only and combined relative changes to the sidecar using the existing relative 1e-8 and absolute 1e-12 tolerances. Check all thirteen dyadic shell values and counts with the same tolerance. These are unweighted sample norms. They are not physical-volume norms or continuous bounds.

At the two inherited angular/radial quadratures, with fresh phases 0.273941 and 0.694327, recompute the physical-volume shell changes and the leading-field gauge. Use each state's own parameters and tail map for its entry replay. Gauge comparisons retain relative 1e-9 and absolute 1e-10 tolerances, phase invariance relative 1e-12. The four stored full-objective rows must be finite and nonnegative and satisfy their decomposition; only the leading-field gauge is recomputed independently. Full pressure-dependent O1 and any optimization outcome remain outside this check.

CPU35, one busy computation, one BLAS/OpenMP thread, CUDA hidden, low priority. Write only independent verifier. No JavaScript/TypeScript, servers/listeners, remote compute, RLScience cluster, Lean/Lake, commits or online posts. Run under a bounded pause of the active holdout tree, with a new output path. Preserve incomplete evidence if the time limit is reached.
