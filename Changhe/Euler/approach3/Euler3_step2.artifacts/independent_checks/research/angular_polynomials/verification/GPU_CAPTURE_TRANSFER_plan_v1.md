# Recorded GPU capture transfer

This plan is recorded before running the independent transfer audit. It reuses the accepted finite CPU reference comparisons V317, V320 and V321. The GPU capture must have identical complete serialized primal arrays, the same starting-state bytes and scientific sources, and the same case, configuration, mode lists and call descriptions. Hash identity is checked before and after reading. Each of the three recorded JVP table calls must match a covered primal argument set at sufficient derivative order under the previously qualified eligibility function.

The audit reads the frozen CUDA run and producer capture metadata on CPU. It does not execute a GPU job. Recorded tensor-equality witnesses are source-reviewed measurements, not independent reads of wrapped tensor storage. No JVP tangent-value or unobserved-branch claim follows. The objective cost is separate from table equality and any difference is retained.
