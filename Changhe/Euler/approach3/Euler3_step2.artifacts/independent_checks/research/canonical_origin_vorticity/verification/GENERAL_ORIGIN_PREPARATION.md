# General origin extension

This work extends the exact-origin argument to the already implemented unrestricted azimuthal class. It does not change the numerical basis. The existing even-mode reader remains unchanged. The new proof and qualification live in ../general_modes/.

Read the standalone proof before the arithmetic controls. No unrestricted-mode checkpoint receives an exact-origin verdict until its complete input is bound and the new implementation has passed its controls. The previous even-mode formula cannot silently be used on an unrestricted-mode field.
