## 1. Coefficient derivative of the fixed discrete weighted residual: CORRECT, with the scope conditions below

The algebra is right. Each step was checked:
- the affine field identity at fixed (c, w);
- f' = 2 tr(DU DV), using cyclicity;
- T4' = DV U + DU V;
- T5' = K f' for a constant linear K;
- Q', h' on a strict branch, F' and G' through the selected maxima;
- v', u' = 2 v v', m' at a fixed lower-median index, z' on fixed cap branches;
- zbar', W', and the product rule for sqrt(W).

Each object matches the production code (problem.py nl_weights_from_ev, residual_vector, residual_vector_wd):
- Q_ks: per node sum_a w_ang |T|^2, times scale_mom^2, then the shell mean Msh. scale_mom = (1 + rho/R0^2)^(alpha/2)
  is a_j. The node weight q_j is correctly absent from Q.
- Clamp: clamp_min(1e-300), then sqrt. This is epsilon = 1e-300.
- Floors: den = sum of the five terms; floor = max(1e-6 den.max(), 1e-300) is F with delta = 1e-6. The far term uses
  den_nl = rms_3 + rms_4 (convection and pressure) with its own floor, which is G.
- Far shells: S_far = the shells with edge >= 1.0, a fixed set.
- Median and cap: torch median of w over the occupied slots is the lower median; the cap is min(w, cap * wmed).
- Normalization: w[shell_id] / w[shell_id].mean() is W_j = z_shell(j) / zbar with zbar the mean over the Nr nodes.
- Residual: (w_node w_ang)^(1/2) scale_mom w_mom^(1/2) R_u is r_ja.
- five_term_split: T1 to T5 as stated, with (DU)_ij = d_j U_i (GU indexed m, i).
- residual_vector_wd differentiates the weights inside the graph. So this is the J_cw coefficient column of the
  momentum rows.

Scope conditions to state when the proof is used:
(a) It covers the momentum PDE rows only (formulation "mom", nu = 0, radial_lambda_w = 0, far_model None, which are
    the production settings). The closure rows, gauge rows and any far vorticity rows are not covered. Under J_cw the
    closure target is lagged; the closure-row coefficient derivative follows from the closure proofs and the tail
    map, and should be compared in a separate block.
(b) The lower-median and selected-maximum branches must be fixed at the base point and on both stencil points. The
    production active-set record (nl_active_set) gives the median shell and clamped shells. The proof also needs the
    two argmax shells (of d_s and e_s) and the floor branches, which nl_active_set does not record. The reference
    should record them itself.
(c) With K kept as the frozen float64 constants, the check is of the derivative of that discrete operator, as the
    proof says. If production adopts the double-double pressure path, the reference must use the same K entries and
    the same source quadrature. The fp64 rounding inside the production evaluation of K f is not part of the
    discrete operator, so the comparison then measures the production rounding as well. That is the purpose of the
    check.

## 2. Exact endpoint expansion of finite radial Chebyshev amplitudes: CORRECT

The identities hold:
- x = q/(s+R)^2 = (s-R)/(s+R), from q = (s-R)(s+R);
- 1 - x = 2R/(s+R), hence 1 - t = 4R/(s+R) = z;
- C_k(z) = T_k(1 - z) has integer coefficients and degree k (induction on the recurrence);
- b_j = sum_(k>=j) a_k c_kj is a finite rearrangement;
- q -> z is smooth on (-R^2, infinity), so two-sided derivatives also exist at q = 0.

The production map matches with q = rho and R = R0: radial.py uses x = (s - R0)/(s + R0), Phi_k = T_k(2x - 1) and the
envelope (s/R0)^(-p) with optional damping. Production forms x = 1 - 2R0/(s+R0), so t = 1 - z is rounded once and z
loses digits at large r. That explains the observed 1e-13 error of the fixed-full stable L at 2^20 R0.

A quantitative remark for the switch radius, which the scope section could carry. The coefficients of C_k alternate in
sign, so sum_j |c_kj| z^j = T_k(1 + z) = cosh(k arccosh(1 + z)), about cosh(k sqrt(2z)) for small z. The worst-case
amplification of the monomial form relative to sum_k |a_k| is therefore T_N(1 + z):
- at r = 256 R0, z is about 0.0156 and sqrt(2z) about 0.177, so N = 47 gives about 2e3;
- at 2^20 R0 the factor is about 1.008.

With long double or exact b_j this does not limit a reference at 256 R0. It does limit a float64 implementation there.
So the switch radius should be chosen where T_N(1 + z) is small, or the condition number recorded. Per channel, N is
the represented radial count.
